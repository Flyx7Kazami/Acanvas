# 文件夹交互性能

2026-10-17–18，分支 `codex/folder-transitions`，对照版本为已合并的 `eb51cd8`。

item 的原生内容继续挂载，独立的 placement 元素承载位置、缩放、透明度和模糊。组过渡使用相同的 420 ms 与 `cubic-bezier(.2,.8,.2,1)`；原生动画结束后恢复普通布局位置，释放变换形成的层。截图和拖动接管读取当前呈现层，减少动态效果的偏好变化会结束正在运行的动画。

布局事务负责暂停新输入，相机动画由会话和交互上下文控制。文件夹内部的展开操作可在布局响应等待期间继续返回父画布，并保留正确的刷新视图。

## 测量

Chrome headless，1280 × 900，DPR 2；固定 500 个 PNG/笔记/Markdown item，其中 200 个在文件夹中。三轮原生控件操作的中位数如下。测量包含点击准备、事务响应、原生过渡及随后 1.1 秒观察窗口；帧间隔来自 rAF，属于浏览器调度指标。

| 操作 | 帧间隔 p95，前 → 后 | 样式重算累计耗时，前 → 后 |
| --- | ---: | ---: |
| 折叠 | 100 → 16.8 ms | 508.4 → 34.5 ms |
| 进入 | 249.9 → 66.7 ms | 924.7 → 41.4 ms |
| 返回 | 99.9 → 66.6 ms | 474.7 → 47.7 ms |
| 根画布展开 | 100 → 33.3 ms | 613.6 → 37.6 ms |

原始数据：[修改前](evidence/folder-performance/before.json)、[修改后](evidence/folder-performance/after.json)。进入和返回仍有内容挂载与栅格化成本，当前场景使用三个小型共享素材。内置浏览器另行验证了进入、展开和折叠的实际点击流程。

## 验证

14 项文件夹检查覆盖进入/返回、展开/解组、重命名、移动、隐藏层吸附、Undo/Redo、动画中途截图和拖动接管、实时减少动态设置，以及布局响应延迟时恢复父相机。另有 12 项编辑历史、6 项吸附/缩放/媒体输入、2 项实际多媒体截图，以及 Fit 动画中断检查。

5%–400% 缩放的 36 组画面对照通过，分别覆盖主画布与文件夹内的前景、模糊背景。笔记的 12 组比较逐像素一致。数据：[主画布](evidence/folder-performance/canvas-quality.json)、[文件夹](evidence/folder-performance/folder-quality.json)。

```sh
TMPDIR=/private/tmp PNG=1 ROUNDS=3 node app/tests/folder-performance.mjs
ORIGINAL_WEB_ROOT=/path/to/comparison/web FOLDER=1 node app/tests/camera-quality.mjs
```

位置与尺寸测试读取当前呈现层或实际布局尺寸。直接写入初始相机的测试先离开旧页面，再建立新场景，避免旧页面的延迟视图保存覆盖测试设置；Fit 测试等待 item 到达画布后再操作。


## 发布前审查（2026-10-18）

Markdown 预览和源码在点击或键盘聚焦后滚动内容；焦点移向其他控件或按 Escape 后，滚轮继续平移画布。Ctrl/Cmd + 滚轮持续缩放画布。点击预览留白仍支持文件拖动，原生文本选择、编辑历史和内容截图继续使用同一内容实例。

重新构建 `eb51cd8` 与当前分支进行 36 组画面对照，覆盖主画布、文件夹前景及模糊背景的 5%–400% 缩放。34 组逐像素一致，12 组笔记全部一致；最小边缘比为 1，最大通道平均差为 0.001857（0–255）。原始结果见上方画面对照数据。

25 项浏览器检查通过，包含 6 项 Markdown/HTML/音频输入检查，并覆盖拖动吸附、独立尺寸调整、对齐、播放中的视频、Fit 中断、内容编辑、IME、Undo/Redo 与刷新。14 项文件夹检查通过，包含动画中截图、拖动接管、实时减少动态设置以及延迟布局保存时返回父视图。

全量 Node 检查共 379 项，其中 36 项依据测试环境设置跳过。首次运行的失败项均已定向复测通过：三项截图检查改为读取可见位置；HTML bundle 和原生 profile 检查使用 macOS 的规范临时路径 `TMPDIR=/private/tmp`；耗时的引用几何检查在有超时上限的独立执行中通过，master 对照也通过。既有 Markdown 批注检查在 master 上复现 Escape 后截图未完成的状态，当前检查通过 Done 完成截图后再发送，并核对完整原文引用。
