## 关键验证证据

1. 双会话隔离、同队列互斥、草稿 revision 条件写入、发送关联去重与发送时内容保存。
2. 产物归属与回执完整性、多对象发布事务、旧 run 拒绝、同任务已有产物的显式恢复。
3. queued/空队列接续、consumer 退休后持续拒绝、重复启动保持现有任务及归属。
4. 未认证与跨站访问限制、项目身份、路径和符号链接边界、媒体 Range。
5. 真实 CLI 完成参考 PNG 读取、独立输出、导入发布、回执及 queue idle。
6. 图片在缩放后进行区域批注，移动/resize 后继续定位；真实短 H.264 视频的时间与帧快照、无法解码文件的卡片反馈。
7. 会话切换期间的迟到保存、草稿双方冲突、发送响应丢失后的查询/SSE收敛、切换期间视图归属保护。
8. SQLite 25 次打开/领取/完成/关闭及强制 GC；独立生产进程多次启动、SIGKILL 恢复、正常 SIGTERM 关闭。
9. 活跃 SSE 与未完成上传下，生产子进程正常 code 0 退出；重启后未完成资产保持未发布，任务和回执可恢复。
10. 亮/暗主题、窄屏焦点与面板关闭恢复、隐藏 dialog 状态、reduced motion，均有真实浏览器检查。
11. 浏览器保持打开，在同项目同端口服务重启后自动更新认证、重建 SSE、恢复持久草稿与队列并继续写入。
12. 同端口服务改为另一个项目时，旧页面保留草稿并停止原上下文写入；上传收到一次 401 后停止重试，新项目资产、临时文件与会话保持原样。发送响应丢失时按 draft 关联查询已提交任务，界面显示唯一任务及正确的新草稿。

独立审查执行 9 组生产 HTTP/SQLite/CLI 断言、生产子进程关闭/恢复、原有 9 个 Chrome 场景，并实际检查代表截图。随后独立验证 3 个追加场景：发送失响应只产生一次 POST 和一条任务；同端口同项目重启保持页面 timeOrigin 并恢复新 SSE 与再次发送；同端口换项目时旧草稿只读保留，上传只发生一次 401 且停止重试，新建会话入口禁用，新项目资产、临时文件和会话保持原样。执行者测试与独立验收分别通过。

## 测量的适用范围

独立传输检查完成 8,397,963 字节文件的完整往返，测得约 39ms。该文件是传输测试素材；完整大视频、编码兼容与内存压力仍需进一步测量。

活跃 SSE/未完成上传的正常关闭，在执行者回归中约 46ms，在独立真实子进程检查中约 7ms。它们是本机测试观测值。

同端口快速重启的 Node HTTP 测试曾复现旧连接池 socket 的首次只读 GET ECONNRESET，后续独立连接的只读探测成功。写操作依据任务/草稿关联查询状态。浏览器持续页面的同端口恢复已通过单独用例验证。
