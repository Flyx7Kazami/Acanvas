## Finder 验证证据与限制

用户说明故障来源是在 Finder 中复制图片、视频或文件。实际故障检查确认旧服务已停止，且旧画布点击未正确转移焦点；两项均已修正。

新版正式页面打开后，用户从 Finder 复制测试文件并在画布按 ⌘V，明确回复“可以粘贴了”。只读检查确认正式项目的对象由 2 个增加为 4 个，新增图片和视频仍可见，现有对象保留。

原生自动化尝试使用隔离项目及 opt-in 测试 helper。helper 完整快照 item/type/data 到内存，在私有 pasteboard 核验恢复等价；任一内容无法完整保存即在写入前中止，恢复时检查 changeCount。成功进入保护窗口的那一次，最终原剪贴板的 item、类型和 flavor 字节已在内存确认等价恢复。

CUA 浏览器键盘走虚拟剪贴板，未发出读取系统原生文件剪贴板的粘贴；计算机使用工具也禁止控制 Codex 原生窗口。因此该尝试没有形成自动化 Finder 通过证据。后续额外原生测试已停止，用户当前剪贴板继续由用户控制。生产功能使用浏览器 File 数据，没有新增从粘贴文本读取任意磁盘路径的接口。
