presence 权限／Origin／未知 API 等普通错误终止并反馈，网络错误按退避恢复，只有明确失效视图重新注册。目录扫描将并行消失的路径作为已回收状态，保留其他 I/O、符号链接、存活 PID 和归属保护。测试按真实原生关闭上限等待进程与 profile 同时退出，成功状态在全部断言后写入；原提前记录成功、短等待失败和 ENOENT 原现场继续保留。
