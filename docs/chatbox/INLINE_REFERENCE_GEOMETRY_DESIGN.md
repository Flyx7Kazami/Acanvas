# 正文引用的状态与行高

日期：2026-10-09（Asia/Shanghai）。状态：实现与专项独立验收通过，合并业务复验及原端口运行更新完成。对应 R02、R04 / A02、A06、A09。

## 需求

浅色预览和正式引用使用相同的名称、图标、DOM 布局、字号、字重、字距、内外间距、按钮、宽度限制与截断方式，状态转换只改变前景颜色。正文引用在亮暗主题及悬停、聚焦状态均无阴影。

引用的完整盒子与正文使用同一行高，缩略图与删除按钮位于该行内部。引用加入、确认和删除保持同一行的高度；真正新增或删除文本行时，输入框继续按内容正常增高或缩回。

## 根因与实现

预览将缩略图和名称放进独立确认按钮，使用 6px 间距及 240px 限宽；正式状态为直接子节点，使用 5px 间距及 180px 标签限宽，造成状态转换时宽度变化。两态改为共用相同结构与几何，只按状态处理颜色、确认行为与可访问名称。

共同内容采用 span；预览提供可访问的确认行为和键盘入口，正式状态保留浏览器原生的引用原子选中与编辑器焦点路径。画板聚焦时点击正式引用，后续输入仍替换该引用；已在正文编辑时保持原有光标行为。窄屏正文统一使用 16px 字号，基础与 media 样式共同管理聚焦、失焦和两种引用状态，避免 focus selector 的高优先级将字号改为 15px。

原引用行高 24px，叠加 padding、border 和垂直 margin 后占用约 32px，高于正文 24px。正文引用按行盒计算完整高度，统一继承文字样式，并准确处理 inline flex 的基线与垂直对齐，避免以固定输入框高度掩盖额外行高。移除共有引用阴影；搜索浮层及其他产品浮层保持自身样式。

## 验收

在独立真实浏览器中比较两态的完整 bounding box、缩略图、名称截断和删除按钮位置，覆盖长短文件名、多引用与文字、纯引用、重复引用、窄屏、亮暗主题和聚焦／悬停。确认与删除不增加或减少剩余文本行的高度，真正换行仍按正文行高增长。键盘确认、删除、原生光标、Unicode／IME 与持久引用行为保持。
