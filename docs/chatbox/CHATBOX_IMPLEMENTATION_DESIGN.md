## 1. 项目运行入口

acanvas 是宿主无关的项目应用。任何 agent 可以通过项目 CLI/API 操作共享白板和明确任务范围；现有宿主对话绑定只提供任务范围解析的便利入口。CLI 的显式会话优先于环境默认；明确给出的 host/thread 继续表达绑定操作。截图运行器属于项目本地服务，其身份使用项目、服务实例、页面和会话，与 agent 产品或模型无关。

用户选择项目管理的 Chrome 窗口作为完整后台截图入口。服务按需建立独立浏览器配置，一会话一个受控 Page，复用已打开页面。CLI 提供 `browser open/status/close`，明确项目及会话；普通项目 URL 继续可用。浏览器实际展示用户正在操作的画板，完成批注后自动取得同一 Page 的合成器画面。运行器显式启用 Chrome 的 OS renderer sandbox，HTML 独立 origin、CSP 与权限边界继续保留。浏览器运行依赖由项目声明，用户现有全局配置保持。

服务停止、浏览器断开或页面关闭时取消本项目的捕获任务并关闭所属运行资源。页面导航依据真实文档身份和绑定路由判断，同文档 history/SSE 更新继续使用当前页面。普通浏览器页通过界面打开受控窗口；捕获能力未就绪时保留批注输入和未完成状态。

## 2. 引用与正文

对象选择动作在正文当前或最后有效光标处生成一次待确认预览，采用浅色与轻微阴影。每个素材各自显示独立预览，多选保留实际选择顺序。用户点击输入区或通过 Tab 聚焦时在原位置消费预览并形成正式引用；程序恢复焦点只恢复编辑。Escape 消费未确认预览，移除正式引用保持消费状态，新的选择动作可以再次产生预览。直接 Send 先确认当前可见预览，再判断请求是否为空，仅引用也可以发送。

正文采用轻量 contenteditable，文本与不可编辑引用原子共同排版。`@` 触发对象及当前会话任务搜索，候选选择在查询位置保存稳定身份并移除当前查询片段；Escape 保留文字。候选展开时 Enter 选择，关闭后 Enter 发送、Shift+Enter 换行；输入法组合期间保持原生正文编辑。对象引用与显式文件附件独立，同资产的不同对象各有自己的身份。

`Draft.references.order` 保存对象/任务的跨类型顺序，各项 `textOffset` 保存其在原始纯正文中的 UTF-16 插入位置；分组 ID 保留便于已有调用读取。服务校验位置、顺序与身份，解析真实名称与来源并在任务快照保存引用条目。旧草稿缺少顺序时按既有对象后任务顺序读取，缺少位置时在正文末尾显示。正文编辑同步移动位置；刷新、队列编辑、任务正文和可读消息使用同一位置规则。新任务引用限定当前会话，旧跨会话引用沿用已完成基础中的延续规则。

新草稿显式对象引用在发送时取得对象状态，失效引用具有移除或重新指定入口。待领取任务编辑沿用已有引用的任务快照，新加入引用取得当前对象状态；捕获现场始终按每条批注独立保存。

## 3. 任意位置批注

全局标记模式明确区分点/区域手势与平移、对象拖动和文字选择。点与区域均先按实际 DOM 绘制确定可见顶层对象，再判断其实际内容区域。内容内位置保存对象内坐标，画布空白及上层媒体留白保存世界坐标；整个区域位于同一可见对象内容内时使用对象区域，跨越边界时保存世界区域。相交和邻近对象只作场景证据。重叠目标允许在完成前改选。

继续使用当前批注评论与媒体范围组件。新流程批注持久保存 `captureState`；点的持久宽高为零，28px 编号中心直接锚定实际点，评论框独立避让与展开，操作命中范围使用屏幕尺寸。图片/视频内容位置、音频选择范围、Markdown 真实滚动及适用的文本锚点、HTML/GIF 可见现场分别记录。文本和 DOM 锚点按实际识别精度表达。

Done 先保存当前批注并取得服务管理的版本，关闭编辑浮层、保留标记，在下一帧交给项目截图运行器。顶部摘要保留缩略图、评论与完成状态；捕获失败显示 Retry/Remove 并保留输入，Send 等待完整证据。评论文字改变沿用现场，目标、区域、锚点或媒体选择改变触发新版本。刷新后先查询既有结果，完整结果复用，原图丢失时明确重拍。

## 4. 后台捕获协议

独立的共享模块 `src/shared/browser-capture.ts` 定义页面与捕获协议。UI 注册 `window.acanvasCaptureController.read()`，提供当前捕获身份、目标、世界坐标、当前视口、裁剪 CSS 区域及真实场景采样。项目运行器向其所属主页面提供 `window.acanvasCaptureProvider.capture(frame)` 与 `cancel(identity)`；身份包含文档、UI 代际、会话、草稿、批注和服务版本。

运行器只在绑定的原 Page 主 frame 工作，逐阶段核对文档、任务身份、视口、布局与滚动。`controller.prepare(identity)` 将固定浮层退出采样画面并等待 DOM 呈现，`restore(identity)` 在采样后或取消、失败时恢复当前文档的控件。Esc 在整个任务中继续取消，指针取消在图片采样结束后恢复。持续媒体的动态像素以捕获帧表达，选择时间和实际播放位置分别保存。应用可控状态变化使用有限重试与总超时。截图取得整页 PNG 后按实际图像尺寸裁剪、缩放，像素映射由实际尺寸计算。

场景集合使用实际 DOM 边界、层级和可确认的不透明遮挡。透明度、圆角或其他遮罩的可见性存在不确定时保留相交候选作为参考证据；该集合表达布局精度，真实像素由 PNG 表达。Markdown 文本锚点来自实际 Range，HTML 表单与运行状态保持原 iframe，截图保存其当时画面。

复用已完成的 prepare/PNG 上传/结果查询/retry 业务接口。取消、超时、导航及目标编辑贯穿整个任务，并通过服务版本使旧工作失效。UI 在成功时采用服务返回的完整草稿；有较新的本地文字或目标编辑时按明确保存顺序合并，服务器管理的版本与证据保持归属。所有异步成功和失败按完整捕获身份处理；当前 job 的同版本提交通知先到时，现场控制器按身份和目标继续结果核对。

## 5. 任务与历史

任务快照保存正文原文、按用户顺序的正式引用、批注用户评论、每条现场、证据资产与来源。共享可读消息生成器从快照确定性输出正文、引用、评论、明确目标、位置/时间、场景证据及截图资产 ID；UI 与 CLI 使用同一文本。持久消息引用资产 ID，导入内容标为参考证据。跨会话历史上下文净化后重新生成消息，保持证据归属。

发送成功后画布只展示当前草稿批注；打开任务时才投影其历史。历史默认阅读捕获截图及其中标记，定位当前目标为独立动作。队列正文编辑保留现场，目标编辑重新捕获，Save edit 保持任务 ID 和序号，取消恢复原草稿。已有批注及任务继续可读。
