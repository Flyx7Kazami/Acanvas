# Request history 呈现与收起

日期：2026-10-13（Asia/Shanghai）。

## 需求与范围

用户要求 Request history 去掉取消说明 `User cancelled the request` 和 `Request text` 原始正文，并在点击任意位置时收起、增加微动效。用户随后明确选择：点击历史面板外收起，内部附件、引用等继续操作。

这是 P0/P2、R05/R06 对应 A07/A08 的历史呈现调整。历史记录、取消原因和请求正文继续通过原任务/API 保存；界面保留原请求摘要、状态、引用、附件、批注、回执及时间。取消态按状态隐藏原因，其他需要用户处理的原因继续显示；`Request text` 原始正文入口从共享任务卡呈现中移除。

## 交互方案

- 历史操作区域外的点击均触发收起，包括画布、输入框、More、工具栏和主题控件。目标控件照常响应，外部点击保留用户新选择的焦点。
- 历史内点击、附件/引用操作及滚动保持展开。关闭按钮和 Escape 提供显式收起及合理的焦点返回。
- 历史打开的捕获详情与当前请求的画布批注属于内部操作区域，定位、关闭详情和批注操作正常响应；点击其他区域收起历史。
- 展开和收起均采用底边固定的 220ms 高度裁剪与 180ms 透明度变化，宽度和横向位置保持；沿用产品现有曲线与表面。关闭中的面板立即退出键盘与指针交互，退出期间恢复紧凑队列，退出完成后移除历史内容。
- 没有待办时完整播放退出；存在待办时回到紧凑队列。快速反向操作从当前呈现连续过渡，减少动态效果时直接切换。
- HTML iframe 获得焦点属于面板外操作，按父页面可观察的真实焦点变化处理；避免内容轮询。

## 验收

1. 真实取消任务的说明与 Request text 在历史中消失，任务/API 中字段保留。Blocked/Interrupted 的有效原因、附件、批注和回执继续可读。
2. 画布、输入框、工具栏和主题按钮的外部点击均能收起，且原点击动作与焦点生效。隔离 HTML iframe 内部点击可收起。
3. 内部点击、引用/附件动作和滚动保持展开；Close/Escape 可关闭并正确返回焦点。
4. 开闭中间帧存在克制过渡，关闭 DOM 保留到结束；待办为 0/多条、快速反向、减少动态效果、390px 亮暗主题均正常。
