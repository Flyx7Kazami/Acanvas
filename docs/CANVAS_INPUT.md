# 画布输入职责

日期：2026-10-06。

## 点击与滚轮分别归属

`data-canvas-control` 表达控件自身负责点击、指针拖动及键盘交互，例如播放键、时间轴和输入框。画布滚轮策略独立决定，控件标记本身不阻断滚轮。

画布内默认由画布处理普通滚轮平移，以及Ctrl/Meta滚轮和触控板缩放。音频时间轴、视频控件、工具按钮和后续新增组件自动继承。音频定位仍由点击、拖动或键盘执行，滚轮只改变画布视图。

需要保留内容阅读滚动的区域显式声明 `data-canvas-wheel="content"`，例如Markdown正文和长批注。普通滚轮交给内容，Ctrl/Meta缩放交给画布。声明 `data-canvas-wheel="canvas"` 可覆盖外层content区域；取离事件目标最近的声明，缺省为canvas。

画布根以外的输入区、队列及其他界面保持自身滚轮行为。现有拖动、缩放手柄操作进行中的画布手势抑制继续生效。

## 公共入口

滚轮归属、deltaMode单位转换及按指针锚点缩放集中在轻量公共模块，画布原生输入和隔离HTML桥接复用同一计算路径。组件名称、文件类型及具体CSS类名不参与滚轮归属判断。

画布在原生capture阶段接收滚轮：属于画布的事件由公共入口处理一次，阻止浏览器默认行为及重复传播；属于内容的普通滚轮继续传递。子组件使用声明表达滚动职责，通常无需自行安装滚轮拦截。

活动HTML的真实滚轮经已验证的私有输入通道到达同一画布入口；画布HTML使用canvas策略，详情HTML保持原生内容滚动。该通道的隔离和生命周期见[HTML悬停交互](HTML_HOVER_INTERACTION.md)。

## 新组件接入与验收

- 只处理控件实际需要的点击、拖动与键盘操作，默认继承画布滚轮。
- 仅在可阅读滚动区域声明content，工具栏、下载及播放控件保持默认。
- 验证普通滚轮、Ctrl/Meta缩放、既有控件操作，以及未注册类型的通用控件默认行为。
- 验证嵌套声明、画布缩放后的锚点、内容阅读区域和画布根以外界面；每个输入只应用一次。
