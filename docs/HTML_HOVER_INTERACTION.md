# HTML 悬停交互与画布手势

日期：2026-10-06。关联 R03、R08、R12 / A04、A11、A14。

## 需求与行为

HTML 节点在鼠标进入时自动交互，移除 Interact 按钮。键盘聚焦及触屏操作提供等效入口，悬停保持原有键盘焦点。节点移出鼠标后继续运行，再次进入更新最近使用顺序。

同页最多保留4个预览实例，初始快照、活动交互和释放交接共用现有许可。第5个交互请求优先释放最久未使用且未被当前指针或焦点使用的实例，复用既有冻结快照与撤销流程。再次访问释放的节点时重新运行；快照保留画面，HTML内部临时状态遵循现有重建行为。

外部 Reload、Stop 和下载继续可用。Stop 在当前鼠标停留期间保持停止；离开后重新进入或明确使用键盘/触摸入口可再次激活。加载失败保留反馈，后续用户操作触发重试。

在画布中的 HTML 节点上，普通滚轮/触控板手势平移画布，Ctrl/Meta滚轮及对应缩放手势按指针位置缩放，行为与图片节点一致。HTML按钮、输入框等内容交互继续可用。任务详情等非画布预览保持原生内部滚动。

用户补充询问Markdown的同类现象。Markdown普通滚动继续用于阅读正文，Ctrl/Meta滚轮和触控板缩放交给画布。普通正文滚动保持现有行为。

随后用户要求音频时间轴和未来组件共用解决方式。画布滚轮与控件pointer职责分离，默认canvas、阅读区域显式content，具体规则见[画布输入职责](CANVAS_INPUT.md)。

## 技术方案

- 预览池按最近使用顺序分配交互实例，继续使用已有状态、快照预算、异步许可及grant撤销流程。
- 静态HTML节点允许事件进入画布滚轮处理。活动iframe使用既有注入桥接捕获真实wheel，画布宿主明确启用转发后才阻止iframe默认滚动。
- 滚轮与活动通知通过预装输入桥的私有 MessageChannel 传递，父页面结合当前grant、有限数值、deltaMode和坐标命中检查处理输入；普通window消息不能直接触发新输入操作。
- iframe使用归一化局部坐标；父页面用iframe的屏幕矩形换算画布指针锚点，保持缩放后的正确位置。原生画布与iframe共享同一平移/缩放处理，统一滚轮单位且每个事件应用一次。活动iframe的真实进入/聚焦通知用于更新最近使用顺序。
- 保留现有sandbox、CSP、预览独立origin与来源验证。服务端注入桥变化后，通过项目CLI正常更新服务，保留当前项目和宿主绑定。

### 输入通道的依据与生命周期

实际Chrome跨进程iframe测试中，CSS `:hover`及父iframe原生pointerenter/leave均可能陈旧或缺失，导致真实重入和滚轮丢失。仅检查内容消息自报坐标命中iframe，又会允许已运行的内容脚本在指针离开时伪造合法wheel消息。grant主键和origin只能识别容器；类型检查无法区分格式相同的伪造输入。Git和版本记录描述代码版本，测试可复现这些问题，均不能隔离同一脚本环境中的输入发送能力。

预装桥在用户HTML代码之前创建原生MessageChannel，私有端点保留在闭包，另一端立即送往父页面。父监听在iframe加载前安装，核对真实frame、opaque origin及当前grant，仅接受该frame/grant的首个初始化通道；同一来源的任务顺序与脚本注入顺序保证预装桥先于内容脚本。后续通道替换被忽略。父页面不在用户脚本运行后向iframe转交输入端口。

桥在用户代码执行前捕获所需原生端口方法、消息数据和滚轮字段读取方法，避免原型改写获取私有端点或篡改输入字段。真实wheel/活动事件经私有通道发送；画布模式配置也经此通道返回。撤销、重载或卸载时关闭通道，旧实例输入保持无效。内容脚本重建自身document可影响自己的预览运行，但不能取得新的输入端点。

## 验收

1. 静态节点悬停后直接可点击HTML控件，界面移除Interact按钮，键盘和触屏入口可用。
2. 连续访问至少5个HTML节点时，活跃iframe及异步grant许可始终至多4个；重复使用刷新淘汰顺序，旧实例释放后保留快照。
3. Stop在当前悬停期间有效，重新进入可激活；快速进出、异步加载、失败和页面隐藏保持资源释放正确。
4. 真实iframe内滚轮及Ctrl/Meta缩放与图片一致，覆盖0.5/1倍画布缩放、缩放锚点及一次性事件处理，按钮和输入仍可操作。
5. 非画布HTML预览保持内容滚动；旧grant、错误来源及非法数值消息被忽略；快照及隔离安全相关回归通过。
6. 自动化使用隔离临时项目，实际服务更新前确认当前无运行任务；用户白板内容和布局保留。
7. Markdown普通滚轮滚动正文，Ctrl/Meta滚轮按画布处理缩放；两者分别验证。
