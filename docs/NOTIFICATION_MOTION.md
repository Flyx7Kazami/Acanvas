# 右下角提示微动效

日期：2026-10-13（Asia/Shanghai）。

## 需求与范围

用户要求右下角现有提示增加从下往上的淡入、淡出微动效。本轮只调整已有通知的呈现，沿用提示内容、产生条件、2.8 秒普通反馈期限、最新前景加薄背板的叠层、恢复操作和既有角落避让。

这是 P0/P2 状态反馈范围，关联 R03/R05 / A04/A05/A07。连接、导入、可操作错误与普通成功/错误提示采用相同方向。相同通知 ID 的内容更新保持现有播放状态。

## 交互方案

- 进入：从下方 8px 上移到原位，同时透明度从 0 到 1，190ms。
- 退出：继续向上 8px，同时透明度降至 0，180ms。过期或撤销后立即退出辅助技术与交互，保留画面到动画结束再清理。
- 普通通知仍在 2.8 秒到期；退出的短暂画面保留用于完成动效。状态通知沿用其业务生命周期，不另设到期时间。
- 连续提示保持最新的一条完整前景及既有薄背板。既有数量上限、普通提示点击穿透、焦点、取消导入和重试/关闭操作保持。
- 通知关闭期间同一 ID 重新出现时，沿当前呈现继续，清理旧退出计时。减少动态效果时直接完成开闭。
- 右侧、底部定位及窄屏避让继续由既有布局负责。视觉过渡与布局测量分开，检查移动中间帧的卡片边缘和阴影裁切。

## 验收

1. 成功与错误提示具有实际进入/退出中间帧，两段均向上，过期退出完成后清理。
2. 普通反馈期限、连续重叠、最新前景/薄背板和提示次数保持，旧提示保持过期状态。
3. 连接、上传和恢复错误状态可以进退，同一 ID 内容更新保持动效进度，退出期间重新出现保持当前状态。
4. 普通提示点击穿透、焦点、取消导入、重试/关闭操作正常；退出中的控件立即停止交互。
5. 390px 亮暗、16px 角落定位、避让及悬停位置、减少动态效果正常。Node 24 两项 `--noEmit`、隔离构建和定向浏览器检查通过，独立审查核对最终源码与实际呈现。
