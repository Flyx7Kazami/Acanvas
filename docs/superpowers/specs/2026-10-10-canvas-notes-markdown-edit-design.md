# 画布便签与 Markdown 编辑

日期：2026-10-10。

## 范围

左侧工具条增加便签。点一次画布，点击处出现一张纯文本卡片，并立刻可以打字。已有 Markdown 块默认仍是现在的预览；右上角增加一组并排开关，眼睛是预览，`<>` 是源码。预览和源码切换只用于 Markdown，不用于便签，也不用于上传的 `.txt`。

## 便签

工具放在选择、平移、标记之后，尺寸与现有工具按钮一致。选中后画布光标为十字。在空白或可落点处点一次，且指针移动不超过 3px，就创建便签；拖动不创建。创建后工具回到选择，便签被选中，文字区域获得焦点。

便签左上角落在点击处。初始 240×128，最小 160×72，可以自由缩放、拖动和删除。拖动使用卡片内文字区域以外的边距，以及对象标题。文字区域里的点击用于输入和选字。Escape 离开文字区域。

文字是纯文本，不解析 Markdown。空便签保留，占位文案为 Note。换行保留。输入停顿约 400ms 后保存，离开文字区域时再保存一次。失败时卡片留在画布上，并显示错误。

存储仍是一份素材加一个画板对象。素材名为 Note，MIME 为 `text/x-acanvas-note`，素材种类仍是 `file`。内容种类是新的 `note`。上传的 `text/plain` 或 `.txt` 继续是普通文件。引用、删除和版本沿用现有对象接口。

## Markdown

只有内容种类为 markdown 的块显示切换开关，位于现有下载按钮左侧。默认预览，渲染与现在一致。源码是等宽纯文本，改的是同一份文件。切回预览、点到编辑区域外，或停顿约 400ms，都会保存。刷新后回到预览。下载前先保存当前文字。

编辑期间不从正文取 Markdown 文字锚点。已有批注保留。源码变化后，旧的文字锚点不重新映射。

## 保存

`PUT /api/assets/:id/content` 替换文件字节并更新大小，素材 ID、名称和 MIME 不变。只接受 Markdown（`text/markdown`、`text/x-markdown`）和便签。其它素材、HTML bundle 和截图证据返回 400 或 403。正文上限 2 MB，空内容允许。同一素材的后一次完整写入覆盖前一次。写入用临时文件替换，数据库更新失败时恢复原文件。成功后发出与其它画板变更相同的变更通知。

界面继续用现有上传接口创建便签，再用画板对象创建接口放置。CLI 不新增命令。

## 验收

- `text/x-acanvas-note` 解析为 `note`，存储种类为 `file`；`.txt` 仍是 `file`。
- 替换接口能写回便签和 Markdown，拒绝图片、普通文本、超限内容和缺失素材；读取到的字节与大小一致。
- 选中便签工具后点一次画布，出现可输入的 Note，刷新后文字还在。
- Markdown 打开时是预览；切到源码后可以修改并在回到预览时看到新的渲染。
