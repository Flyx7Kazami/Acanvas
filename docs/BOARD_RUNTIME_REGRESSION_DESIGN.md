# HTML 预览、手势与画板性能修复

日期：2026-10-09（Asia/Shanghai）。状态：实现与专项验证完成，独立验收、默认回归及运行结果见[专项验证](BOARD_RUNTIME_REGRESSION_VALIDATION.md)。基于 `c3856c1`，对应 R02、R04、R11、R12 / A02、A06、A07、A09、A13、A14。用户报告 HTML 变为 Preview unavailable、手势无法缩放及拖动显著卡顿。

## 已确认原因

当前默认 HTML 页的实际错误为 `429 surface_limit`。后台容量默认是整个项目四个表面，每页三个 HTML 时，另一页只剩一个名额。隔离正常 CEF 双页面复现第一页 3/3、第二页 1/3；容量错误进入不可用状态。源码同时缺少与具体 view 绑定的连接活性，页面突然结束时源实例仍可占用名额。

滚轮路径展开原生 WheelEvent 时丢失浏览器原型访问器字段 `ctrlKey/metaKey/deltaMode`，把缩放当成平移。每次又以最近已呈现相机为起点，连续输入会覆盖前次尚未呈现的结果。实际 App 中 24 次 Ctrl-wheel 后仍为 1×，正确累计为 1.6160744×。

1440×1000、DPR2、12 个混合对象、4 个正常 CEF HTML 与评论场景中，每个内容／视图通知同步绘制完整画板，反复分配大 Canvas、回读并重置可见 Canvas。修正输入与真实提交配对后的拖动样本有 285 次呈现、约 2.782 秒同步像素回读；全活跃样本约 3.501 秒回读。Trace 确认主场景 `getImageData` 占主要阻塞，布局读取与 GC 分别记录。性能结论采用相同环境／fixture 的前后实测，跟踪开销与当前测量范围单独声明。

## 修复方案

HTML 表面按完整 view 身份分配资源：每 view 默认四个活动实例，项目总活动上限默认十六，显式 `maxSurfaces` 仍表达项目总量。既有历史表面数量和帧字节界限继续工作。项目总量及历史表面数量的暂时容量错误（`surface_limit/surface_retained_limit`）采用 500ms 起、5000ms 封顶的可取消退避；每 view 上限、权限／归属等错误沿用明确错误状态。帧字节预算采用既有帧采样错误／恢复路径。多个页面保留各自表单、脚本状态、源帧和声音归属。

视图增加认证的 presence 流式连接，身份包含项目、会话、document、view 与 generation。最后一个连接结束后采用五秒断线宽限，重连取消清理；清理前确认旧身份仍对应该视图且没有新连接，再释放具体 view 与原生实例。正常页面退出通过小体积 keepalive 请求明确关闭；隐藏及缓存页面事件保持实例，实际缓存行为按测试结果声明。已绑定批注来源和持久 PNG 保留，presence 属于运行资源生命周期，捕获操作序号继续由原业务接口管理。

滚轮输入明确读取全部字段，事件间同步推进当前输入视图，按用户输入累计相机变化。WebKit 手势采用相对起点 scale，双触点按距离和中心处理，重复渠道和取消／切换正确结束；标准内容滚动、单指拖动与 Mark 操作保留各自语义。呈现相机继续用于现场证据与已显示对象命中，输入累计视图用于处理尚未绘制的连续动作。

画板渲染以一次 RAF 合并实际失效通知，过滤无关 DOM 变化。renderer 持有私有 staging Canvas，同尺寸重复使用，绘制成功后同步提交像素及不可变元数据。该画板入口只接收基础绘制 primitive 和已经在 publish 边界复制、验证 origin cleanliness、保持私有像素的 SceneContentFrame 纹理；运行时逐项检查字符串绘制字段及有限数值，颜色等字段采用字符串，CanvasPattern 留在通用来源验证路径。未知纹理／直接图片使用通用独立 SceneFrame 验证入口。通用外部 Frame 的不可变性继续保留，绘制失败维持先前已显示像素与记录。

Done 仍同步复制当前可见 N 及对应元数据，编码和传输处理独立副本。DPR／实际像素尺寸、CSS 原点与缩放、完整图层、批注标记、同帧来源、未上传恢复、旧截图和权限校验保持。性能改动由实测决定，呈现质量沿用当前设置。

## 验收与交付

验证正常 CEF 多页资源、独立输入状态、刷新／关闭／创建中关闭、真实浏览器 context 终止、短断线恢复、新 generation 隔离及已持有 N 提交；验证真实原生 WheelEvent 字段、高频累计、锚点、内容滚动、CDP 双触点及单指行为。合成 WebKit 事件与真实物理触控板／Safari 的测试范围分别声明。

性能测量区分静止、拖动、平移、缩放、媒体与 HTML 全活跃，记录输入至实际 Canvas 提交、绘制／分配／回读、长任务及相关进程成本。同 fixture 的前后测量保留原始 trace；功能回归包含旧 Frame 不变、污染失败保留原画面、同 N PNG、取消／刷新／服务重启及本轮八项交互。

测试使用独立项目、端口、素材和 profile，构建先输出到独立目录。执行及独立审查由不同子智能体完成，主智能体维护方案和实际验证记录。正式服务通过受控接口更新并比较用户业务内容；Git 提交由主智能体在验收完成后执行。
