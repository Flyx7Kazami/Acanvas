## 1. 产品目标

让用户和 agent 在同一份项目白板上持续创作。用户导入参考素材、选择素材、添加批注，并通过白板 chatbox 发送需求。需求保存在当前宿主对话绑定的任务范围的本地队列；agent 按顺序处理，生成产物回到共享白板。

核心归属：项目共享创作内容，宿主对话独立推进需求。白板自身提供 annotation、附件草稿、chatbox 和 queue。通用 Skill 指导 agent 使用本地 CLI；各平台原生 annotation 和对话驱动接口作为后续可选增强。

产品界面只呈现项目画布与任务。宿主 agent 的对话身份负责任务隔离；存储中的 session ID 是内部任务范围标识。用户通过绑定链接使用白板。

## 2. V1 范围与运行条件

V1 支持单机项目、本地用户和多个宿主对话绑定的任务范围。浏览器、agent、CLI 必须能够访问同一运行服务和项目素材存储。项目数据存放在本机文件系统；云端 agent、跨设备协作与网络共享盘需要后续适配。

首轮验证使用 macOS 的 Chrome 和 Codex 内置浏览器，并记录 Safari 的兼容性。通用 Skill 以 Codex 和 Claude Code 为目标验证宿主；实际支持列表只列出已经完成验证的组合。第二宿主不可用时，将该项保留为待验证。

V1 文件类型包括图片、视频和任意文件附件。图片显示预览，视频按浏览器解码能力播放，其他类型显示文件卡片。视频批注支持时间点或时间区间、画面快照和区域批注。完整视频理解由具体模型或解析工具提供。

后续扩展包括 Pinterest 自动搜索与导入、特定图像生成提供商、云端接入、原生桌面剪贴板增强和宿主主动启动任务。V1 先完成导入、批注、入队、执行、回填与恢复的完整链路。生成能力通过宿主已有工具或显式配置的服务接入，具体 image2.5 服务接入时确认其接口。

## 5. 素材导入与 annotation 链路

1. 用户从任意位置粘贴或拖入文件，或通过右上角悬浮导入按钮，先创建共享画布素材对象；通过选择素材或添加批注建立需求引用。普通文字粘贴保持编辑行为。
2. 三种入口统一处理浏览器提供的 File/Blob。文本路径保持文本；浏览器 API 使用 asset ID 访问已导入文件。
3. 文件流式写入项目素材目录，完成后登记资产；上传状态与任务状态分别记录。附件就绪后允许发送引用它的需求。
4. 用户选中一个或多个素材，通过 Annotate 进入二级，在素材旁输入整素材批注或直接拖动区域再输入。Done、Escape 或 Ctrl/Cmd+Enter 结束本条编辑，保留非空草稿；Enter 换行并保持输入法组字行为。视频批注保留媒体时间和画面快照。
5. 新批注的非空正文进入当前任务范围的同一份持久草稿，并在 chatbox 中形成批注引用；普通草稿中的已有批注也可继续编辑。移除引用只改变本次任务内容，来源素材保持。
6. 用户发送时，将指令、附件、批注及明确引用保存为任务；此次新批注保存项目记录及任务快照，默认隐藏画布标记，显式查看任务时投影。任务中的批注副本保持发送时内容。
7. 项目批注记录保留为来源与归档；界面编辑当前草稿实例，已发送任务保存当时的快照。首版保持已有引用可读，不提供全局回写历史批注的编辑入口。
8. 发送成功后结束此次草稿并建立新的 draft ID，新的附件和文字进入新草稿；提交失败时保留原草稿。一次发送使用该次持久 draft ID 作为提交关联，数据库约束每个 draft ID 对应一条任务。重复提交返回已有任务；响应丢失后先查询该提交关联，再更新页面。

草稿使用普通 revision 条件写入，保存和发送均携带已读取版本。洁净草稿接收服务端更新；本地未保存内容遇到外部更新时保留双方文本、附件和批注，由用户明确选择后再保存。

点击对话框中的批注标签、画布编号或短评访问同一批注。当前草稿可以编辑，任务快照展开为只读全文；任一时刻只有一条激活。Done、Escape 或 Ctrl/Cmd+Enter 结束局部编辑并返回原入口，任务提交由底部 Send/Save edit 完成。输入框聚焦保持原底色、边框和阴影，没有额外 highlight；按钮保留键盘焦点反馈。普通点击保持画布位置，界面不提供 Locate。

编号气泡、短评、全文和编辑器保持屏幕尺寸，按素材的画布锚点换算屏幕位置。平移和缩放时锚点跟随素材，气泡和文字保持可读大小；素材及区域轮廓继续随画布缩放，chatbox、工具栏和视频播放控件也采用屏幕尺寸。批注位于关联素材外侧，同源多条按稳定顺序排列，边缘允许裁切；阅读与编辑共用全文区域，保持一致的屏幕尺寸与锚点关系。原素材已移除时，已发送任务的来源快照继续可读。

创建与编辑共用草稿中的批注身份。异步视频帧回填绑定原任务范围、草稿及批注 ID，只补充该记录的媒体字段；已移除或取消的批注保持移除状态。发送等待当前必要的帧处理和草稿保存，包含当前输入的最新内容，失败时保留本地编辑与原任务。

图片批注保存 asset ID、对象 ID、对象内部归一化坐标和文字。视频增加时间点或区间及快照资产。画布区域批注保存世界坐标、涉及对象的明确引用和选区预览。预览用于理解空间关系，原始素材用于读取和生成。

截图及浏览器提供的剪贴板文件纳入支持范围。Finder 中任意文件的复制粘贴按系统、来源程序和浏览器实际测试结果声明。拖拽与选择文件提供通用导入入口。视频播放按容器、编码和平台测试；无法播放的文件以文件卡片保留，并说明预览状态。

## 6. 宿主绑定、上下文与任务归属

宿主绑定在项目内持久保存 `(host, thread ID) → 内部 session ID`。同一宿主对话重开复用任务范围，不同对话默认隔离。Codex 直接执行可使用可信 `CODEX_THREAD_ID`；主 agent 委派技术执行时显式传递父对话或已有绑定链接，避免子 agent 的临时身份产生错误新队列。

CLI `project open` 返回准确绑定的页面地址。原有 session URL 继续指向已有任务，显式接续保留历史。绑定冲突通过明确错误处理；界面据 URL 路由，去掉按项目 localStorage 或首条 session 猜测目标的行为。独立浏览器缺少绑定 URL 时使用每标签页稳定的内部范围并写入 URL，刷新继续当前任务。

任务保存用户明确选择的对象、资产、批注和前序任务 ID。恢复时读取相关历史及产物；自然语言指代有歧义时进入 blocked 请求补充。待领取需求支持回到输入框修改，发送后保留任务 ID 和原队列序号；执行中的需求保留当前快照，后续反馈形成关联需求。

## 7. 队列与执行状态

任务状态如下：

| 状态 | 含义 |
| --- | --- |
| queued | 已保存，等待领取 |
| editing | 用户正在修改待领取需求，保留原队列位置；消费者到达此项时等待发送或取消修改 |
| running | 已由当前执行尝试领取 |
| blocked | 需要信息、依赖结果、权限处理或冲突决定，当前队列暂停 |
| interrupted | 执行异常结束或结果需要核对，等待显式恢复 |
| completed | 需求已交付，产物与回执已登记，适用验证已完成 |
| cancelled | 用户撤回待办或明确跳过，保留原因及历史 |

一次发送是一条任务，包括本次全部批注和 instruction。完成按 task ID 记录，历史可折叠查看。completed 表示已交付；用户的新反馈形成后续需求。

待领取任务通过本地服务进入 editing。短事务同时核对状态、保留原任务快照与当前输入草稿、创建关联任务的编辑草稿；任务领取与开始修改按同一事务规则竞争。编辑草稿沿用 revision 条件保存，刷新恢复当前修改。发送以同一任务 ID 和序号替换需求快照并恢复 queued；取消恢复原任务内容。发送和取消均恢复进入修改前的输入草稿，已完成的编辑提交可按编辑草稿 ID 查询结果。引用原快照中的素材和批注，保持发送时来源；新增引用按正常草稿校验。队列可处理编辑项之前的需求，到达编辑项后等待用户结束修改。

每个 session 队列同时由一个消费者执行。不同 session 可以并行生成与处理。领取采用短事务：验证消费者归属，检查当前阻塞或运行项，领取最早 queued 任务，创建本次 run ID，然后提交事务。外部生成期间保持数据库可访问。

执行循环：领取任务 → 读取素材及上下文 → 执行与记录进度 → 保存产物 → 发布白板变更及回执 → 完成任务 → 再次领取。用户在执行期间追加的需求进入相应宿主对话绑定的队列，任务边界重新读取。

当前项 blocked 或 interrupted 时暂停该队列。用户补充后恢复，或显式跳过后继续。queued 撤回通过条件更新完成；执行中用户停止时记录停止请求和已知进度，并核对已启动的外部操作及迟到结果。

读取空队列与将消费者置为 idle 在同一短事务中完成。该事务之前入队的请求继续被消费；之后入队的请求显示“已排队，等待继续”。白板消息持久保存，agent 下一轮启动仍由用户口令或已验证的平台适配器负责。

默认恢复口令：

> 继续处理这个项目白板的任务。项目：`项目路径`；白板：`当前绑定链接`。先核对未完成任务和已有产物，再按顺序处理；完成后登记产物与回执，队列为空或需要补充时停止。

## 8. 接续执行与迟到结果

区分持久任务范围（内部 session）、队列消费者和每次任务执行 run。每次领取产生执行记录；进度登记、对象发布和完成操作均验证当前消费者、run ID 及任务状态。

消费者执行记录使用 session ID 与 consumer ID 关联，并保存 active/retired 状态。每次激活使用新 consumer ID，单次循环内保持稳定；idle 释放、显式交接及真正服务重启会结束相应消费者。已结束身份持续保留历史，后续请求获得明确冲突提示。领取与 idle 释放均验证当前归属，显式无运行项接续以事务完成；运行项先核对已有进度与产物。重复启动被拒绝时保持现有任务与执行记录原样。

显式接手首先核对旧执行状态和已知外部 job。时间超限表示需要检查，执行归属的转移需要明确处理旧执行。旧 run 的迟到回填进入冲突处理，保留结果记录供核对。

每个 run 使用独立产物目录。已知外部 job ID 尽早登记，恢复优先查询同一 job。结果不明时保留 interrupted；恢复决定依据已保存产物、外部查询及用户确认。

记录“产物已生成”和“白板已提交”两个进度点。产物保存后发布前中断，可复用已有文件；数据库提交后响应丢失，可按 task/run 查询已提交回执。外部生成和计费能力由提供商接口决定，本地事务负责本地记录及发布。

## 9. 共享白板更新与发布

UI 和 agent 使用同一对象操作接口，提交新增、移动、修改、删除等明确操作。对象位置属于共享布局；视口和选择保存在 session 视图中。

已有对象采用普通整数 version。版本条件与更新在同一数据库操作或短事务执行；失败进入冲突处理。多对象任务先保存产物，再在一个事务中检查相关对象版本、发布对象变更、写入回执并完成任务。

需要分阶段交付时，明确记录每阶段提交的对象和结果。恢复依据已提交阶段继续。生成结果默认添加新对象；修改已有对象使用其当前版本。客户端通过增量通知后读取最新状态，避免旧视图保存时丢失其他宿主对话的内容。

发布操作实际引用的产物资产与完成回执一致，并核对任务归属；同任务已有 run 的产物可用于显式恢复。纯布局或文字交付记录实际操作与摘要。原有素材的来源持续保留。

## 10. 持久化、素材生命周期与备份

项目运行目录：

```text
.acanvas/
  board.sqlite
  assets/<assetId>.<ext>
  previews/<previewId>.<ext>
  outputs/<taskId>/<runId>/
  tmp/
```

数据库保存项目、内部任务范围、草稿、资产、画布对象、批注、任务、附件引用、回复、执行尝试和回执。关系使用普通主键与外键；任务顺序使用持久序号。大文件保存为磁盘文件，数据库记录相对路径与元数据。

附件导入顺序：流式写临时文件 → 完成并关闭文件 → 改名为最终文件 → 数据库事务登记资产及引用 → 返回成功。文件与 SQLite 分别持久化，恢复时检查具体记录和文件。初版允许保留未引用文件，优先保证已提交任务的引用完整。

移除画布对象只解除该对象引用。历史任务、批注、回执、持久草稿引用的资产继续保留。初版采用显式备份和恢复，自动垃圾清理安排在后续独立任务。

备份通过 SQLite 备份接口创建一致数据库副本，按副本引用复制素材，备份期间保留这些资产，全部完成后发布备份。恢复在独立目录核对引用，再由用户选择使用该数据目录。普通进程中断恢复纳入 V1；突然断电场景的持久性在目标系统另行验证后声明。

项目根以明确指定的数据目录解析，并规范化实际路径。素材保存相对路径，项目整体移动后可重新打开。独立 Git worktree 默认使用各自白板；用户可显式指定同一白板目录。项目目录复制后分别使用各自数据，项目名称和记录 ID 均用于识别与展示，不触发自动合并。

## 11. 技术选型与接口职责

- 前端：React、TypeScript、Vite；DOM 承载图片、video 和文件卡片，SVG 承载选框及批注。
- 本地服务与 CLI：TypeScript 编译为 JavaScript，共用业务接口和类型；服务提供 HTTP API、静态页面和 SSE。
- 数据库：SQLite，使用 better-sqlite3。短事务执行状态变化与对象发布；配置并测试 WAL 和合理的 busy timeout。
- 运行时：V1 支持 Node.js 24 LTS，具体补丁和依赖在实施时通过安装测试与锁文件记录。better-sqlite3 作为原生运行依赖，按首发 OS、CPU 架构与 Node 组合验证。
- 媒体：浏览器本地预览、HTTP Range 视频读取；ffmpeg 作为可选的抽帧或预览转换工具，原文件持续保留。
- 发布包：包含编译后的 CLI、本地服务、前端静态资源和运行依赖。Skill 调用 CLI；用户运行时使用构建后的页面。

独立服务由 `project open` 发现、身份核验或 detached 启动，运行日志和无凭据 descriptor 保存在项目运行目录。`project status/stop` 核对规范化根目录及服务实例；停止通过当前已认证服务执行。后台服务生命周期独立于临时 agent 执行回合；当前实现保持系统服务与全局配置原样。

服务端构建更新后，已启动进程继续执行其加载的代码。交付涉及新增接口时，分别核对前端资源与实际服务接口；确认执行任务已结束后，通过项目停止、打开命令在原端口更新进程，再读取原任务范围核对队列与素材。构建测试及实际运行服务的验证结果分别记录。

当前全局 Node 20.19.5 保持原样。本项目已使用私有 Node 24.21.0 验证 TypeScript 5.9.3、better-sqlite3 13.0.3 和 Vite 7.3.6；依赖锁文件记录实际组合，项目脚本自动选择私有运行时。安装、启动和检查命令见 [README](../README.md)。

拟议 CLI 能力包括 project open、session create/acquire/resume、asset import/read、draft send、task next/read/block/complete、board operations 和 backup/restore。以上是接口职责，具体命令在实现时形成帮助文档。所有写入经本地服务执行。

SSE 用于浏览器状态更新；断线后读取当前状态即可恢复视图。它的生命周期与 agent 执行分别管理。MCP 可作为后续工具适配层，V1 优先验证 CLI 工作流。

## 12. 安全与信任边界

本地服务具备项目文件权限，监听回环地址并验证 Host、浏览器 Origin 和访问凭证。状态变更使用受保护接口，GET 保持只读。CLI 使用受认证的调用渠道；浏览器来源缺失时仍需验证调用方。运行访问凭证经受保护的运行渠道交付，日志和 Git 中保存可公开的元数据。

浏览器固定首次确认的 project ID 与规范化根目录，重新认证时先核对项目身份，再更新访问凭据及重试；同一端口出现另一项目时保留原上下文并停止写入，用户明确重新打开后再建立新绑定。CLI 每次调用验证用户指定的规范化项目根目录，并使用本次认证渠道；内部 session 与消费者参数明确绑定当前操作。

浏览器用 asset ID 访问资源，服务在授权项目目录内解析路径，覆盖路径穿越和符号链接越界。文件导入上传实际字节；CLI 产物导入检查明确的授权目录。

HTML 原始附件通过下载接口提供，自包含 HTML 与本地资源包的交互预览采用独立 host/origin、短期入口及资源集合授权和 opaque-origin iframe。可视区域内的 HTML 自动生成静态快照，用户激活后交互；同页最多运行 4 个实例，快照生成与交互共用名额。移出视野或停止后释放实例、保留可用快照，快照不恢复内部运行状态，也不写入任务引用。SVG 使用受限图片或静态预览。文件名、批注和其他文本按文本渲染。

GIF、Markdown、音频及隔离 HTML 的统一扩展方案见[多模态画布设计](MULTIMODAL_CANVAS_DESIGN.md)。音频按最新确认采用 A 紧凑布局、可定位的完整音频响度波形与内嵌封面；HTML 自包含预览通过独立 origin 和受限资源通道执行。

任务数据明确区分用户 instruction、用户批注与 reference content。附件文字、网页内容、OCR 和工具输出带有来源，作为参考材料传递。Agent 继续遵循宿主工具权限；白板入队保存需求及意图。

## 13. Skill 工作流

Skill 使用 Agent Skills 目录形式，包含 SKILL.md、脚本和所需资源。它描述启动或连接服务、确认项目与宿主任务绑定、领取任务、读取真实素材、处理需求、登记产物、发布结果及恢复的步骤。

启动时验证运行环境、服务可达性和实际项目与宿主任务绑定。图片和文件通过可访问资源读取；浏览器临时 blob URL 仅用于页面预览。所用 agent 必须具备执行 CLI 及所需素材处理工具的能力。

Skill 指令负责引导模型，持久状态与并发约束由服务和数据库执行。完成提交包含摘要、产物引用和适用验证记录；服务核对状态、归属及文件引用。艺术目标是否满足用户意图通过用户后续反馈和具体验收判断。

恢复和错误信息写入当前宿主对话绑定的任务范围。新需求在下一任务边界读取；需要澄清时保存原因并等待用户。普通聊天中的 agent 通过明确口令进入白板消费流程。

### 2026-10-02 交互修订验收范围

1. 队列和任务详情展开、收回均呈现非线性及轻微超伸；鼠标从入口移向内容时可连续操作，减少动态效果模式直接切换。

6. 队列为空且空白失焦时输入框收窄，聚焦以超伸动画变宽；存在队列、已有文字或编辑内容时保持展开宽度。

8. 画布图片、视频和文件显示直角；四角缩放保持对角锚点，支持最小尺寸、缩放视口下的吸附参考线、Alt 临时绕过及布局持久保存。

## 16. 已知边界与设计决定

- 架构审查确认方向可行；真实浏览器、宿主和故障恢复行为由原型验证。
- 浏览器提供的剪贴板文件可以导入；各系统的任意文件复制粘贴按实测声明。
- 队列保存与 agent 启动分别处理；空队列退出后通过口令恢复。
- 项目共享对象，宿主对话独立任务；对象修改采用原子版本更新。
- 内部任务范围与执行尝试分别记录；接手和迟到结果通过当前执行归属校验。
- 外部生成结果不明确时暂停核对；恢复优先使用已知 job 和产物。
- 草稿归当前宿主对话绑定的任务范围；发送时保存任务与项目批注记录，画布按显式查看投影，原始任务内容持续保留。
- 素材引用覆盖任务、批注、草稿及历史；初版保留孤立素材，后续再实现清理。
- 本地文件服务和素材预览处于明确安全边界；具体限制通过 A14 验证。
