## 恢复依据

完整历史 HTML 未保留。先前版按留存的源码参数、渲染结构和截图重建，同时保留当时的卡面中心深度排序。恢复后的 HTML 为 70,942 字节，与首次灰阶构建记录相同。

执行者以相同视口和 DPR 复拍 0、75、150、225、300、375、450、525ms，8 个时间点组成的截图与留存记录逐像素一致。独立复拍在 655,360 个像素中仅有 1 个边缘像素不同，最大通道差 20；两次观测分别记录。该结果支持忠实的视觉恢复，文件来源仍为重建。
