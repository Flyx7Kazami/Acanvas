# Item 分组与文件夹画板

日期：2026-10-13（Asia/Shanghai）。需求对应 R01、R03、R04、R08、R10 / A01、A06、A11、A12；新增 R14 / A15。

## Group 展示与引用修订（2026-10-13）

二级导航为透明、无边框、无阴影的轻量横排，使用 32px 动作按钮。Frame 标题和二级导航只展示组名；folder 下方 caption 只保留名称。封套名称与右下数量按现有网格对齐。分组、解组、改名、收纳/展开和返回图标默认采用相邻 IconButton 的辅助色，悬停采用正文色。

选中 frame 或 folder 形成一个 `group` 引用，预览和正式正文都以组名呈现，并使用对应组主色的 16px 简洁文件夹缩略图。Ink 色图标增加细的辅助色轮廓，填色保持原组色，明暗主题都可辨识。每个引用沿用一个原子编辑单元；独立选择 item 仍产生 item 引用。`@` 候选提供组名和同色图标，重复引用保留各自正文位置。草稿保存 group ID 及引用顺序，发送时冻结组名、颜色、模式、版本、成员 ID、world 布局及原素材元数据。任务和 CLI 可读同一组来源，后续改名、转移成员或解组保持已发任务快照；历史与历史编辑采用保存时的组名和颜色。素材文件本身继续使用现有资产内容接口。

Folder 直接 Ungroup 使用同一次解组事务，成功后在实际最终布局上呈现约 420ms 非线性展开，folder 的短暂视觉和原成员身份用于到达动画。短暂视觉只服务呈现，保持非交互并随过渡结束移除。二级解组同时回到父视口，减少动态效果设置直接采用最终状态。外围磨砂为 blur12px、opacity .22，组内内容和控件清晰；DOM 和 Done 共用同一背景模糊参数及实际帧几何。

## 封套细节修订（2026-10-13）

文件夹采用现有六色与 216×224 封套、216×256 布局。左列档案线条向左靠齐，保持上密下疏并延伸到封套底部留白之前；右列使用相同网格显示真实 group 名称和 item 数，长名称在列内截断。外部 caption 保留原位名称编辑。背板开口高度降低，封套使用更小圆角，顶部预览直接显示素材内容。

网格两侧留 14px：左线从 x14 延伸至 x108，y 坐标为 102、104、106、108、110、113、117、122、128、135、143、152、162、173、185、198、212，最后一条线距封套底约 12px。右列从 x138 至 x202，分隔线 y102/152/212；左右线条统一采用 1px 线宽与 y+0.5px 像素对齐。名称位于 y112、宽 64px，以 14px 字号和 18px 行高最多两行；数量位于 y190，右对齐至 x202。背板整体下降 16px，前盖四角为 4px、tab 转角约 3px。预览图片和视频内容铺满 72×106 卡片，保留素材自身像素。

Hover 时前盖和预览轻微展开，采用 220ms `cubic-bezier(.2,.8,.2,1)` 过渡；前盖以底边为轴缩短至 97.5%，预览向上移动 6–8px 并小幅向两侧展开。文件夹的画板位置、占位和命中区域保持稳定。操作条与文件夹之间保持连续命中，键盘及触屏可达，减少动态效果设置采用静态状态。捕获 Done 时使用当前呈现的封套与预览几何和同一文本换行。

Group 的选择、hover 与 focus 由同一交互状态表达。显式选择 group 或 item 时接管当前目标；后续 hover 可显示对应文件夹操作，离开或失焦只释放该来源对应的 group。操作条与微展开共用当前 hover/focus 目标。显式选择 frame 标题或非 item 空白后可继续改名、收纳和解组；folder 保持 hover 操作及进入二级画板的原行为。点击路径以可复现的真实场景验证，成员的独立操作和普通整组外观保持。

文件夹封套单击进入二级，外部 caption 的名称单击选中整组并形成一个 group 引用预览，聚焦对话框后成为正式引用；caption 也可拖动整组。Tab 聚焦后 Enter/Space 选择，触屏 tap 使用相同入口。名称编辑时 caption 采用输入语义，保持原位打字。成员操作条避让可交互的 frame 标题，让标题中心保持可点击；外围虚化且 inert 的标题继续交互隔离。

## 产品行为

框选或 Shift 多选至少两个一级画板 item 后，选区工具条提供 Group 图标按钮。创建后出现包围成员的方框，标题采用 Group N 默认编号，可在画板原名称处重命名。成员继续独立选择、编辑、移动、缩放和批注；框的标题和非 item 的空白区域均可选择整个 group 并拖动。整组选择使用独立 group 选择状态，保持普通外框和成员外观。group 的 Rename、Store in folder、Expand on board 和 Ungroup 使用纯图标按钮。Ungroup 保留全部成员与素材。

悬停操作条与二级导航共用同一组图标和顺序，当前模式显示对应切换动作；返回采用标准左箭头。全部动作使用 32×32 按钮、16px 正文色图形及轻量悬停反馈，保持紧凑排布。图标采用具体对象与单一方向动作：Rename 为带短基线的铅笔，Store in folder 为箭头进入文件夹，Expand on board 为箭头从文件夹出来；Group 与 Ungroup 使用用户选定的 Font Awesome 成对图形；收纳和展开采用相同文件夹轮廓、相反箭头方向。按钮保留 tooltip 与无障碍名称，动作文字仅用于这些辅助信息。320px/390px 导航保持紧凑、原名称及输入可读可达。键盘及触屏入口与鼠标一致，操作条保持 hover 连续命中，名称编辑保持原位普通外观。

Group 与 Ungroup 采用用户选定的 Font Awesome Free Regular 原版 `object-group`、`object-ungroup`。保留原 SVG path、576×512/640×512 viewBox 和原比例，以 16×16 图形槽等比显示、使用正文色填充；保留版权与来源声明。其余改名、收纳/展开和返回图标按现有规则呈现。选区操作顺序为 Group（适用时）、颜色/对齐（适用时）、Delete；删除始终位于当前选区工具条最后，tab 顺序与视觉顺序一致。选中 group 时沿用自身操作，Ungroup 保留成员。

新 group 的默认名称为 `Group 1`、`Group 2` 等项目级编号。服务在创建 group 的同一短事务内分配递增编号，重启或解组后继续编号，并避开当前已存在的 `Group N` 名称。显式传入名称和用户改名保持；既有 group 名称保持。失败的创建事务同时回滚编号分配。UI 与 CLI 使用同一命名规则。

文件夹模式隐藏一级上的成员，封套视觉为 216×224，布局占位为 216×256（包含下方名称的 32px 区域），左上角锚定当前 group 外框左上角。单击文件夹进入二级画板；拖动文件夹移动其占位及全部成员。键盘聚焦后 Enter 进入。悬停文件夹时即可显示操作，操作条与文件夹之间有连续命中区域；移入操作条后保持显示。键盘聚焦提供等效入口，触屏沿用可达的组操作。二级保留导入、便签、编辑、媒体、平移缩放、选择、对齐、批注和聊天引用；新建 item 自动加入当前 group。当前 group 的成员清晰呈现，其外围一级内容虚化且保持交互隔离。Back to board 返回一级并恢复进入前的视口。范围是一级和二级两层，分组入口用于一级成员。

Rename 把 frame 标题、folder 下方名称或二级导航名称原位替换为无边框、无底色、无 outline、无阴影的输入；原文字的字号、字重、位置保持。Enter 或失焦保存，Escape 取消，输入法组字期间 Enter 用于候选确认。原位编辑期间保持普通外框与成员外观，当前标题文字按原生编辑方式选取。

文件夹进入/返回、外框展开/收起及周围布局切换使用约 380–460ms 的非线性过渡；组的变化与相邻 item 的位移连贯呈现。缩放按钮、百分比复位和 Fit 使用非线性 camera 过渡，快速连续点击从当前显示位置继续到累计目标。触控板连续缩放和拖动保持直接跟随，手势可随时接管动画；按下时以该单元的实际显示坐标作为拖动原点，首帧位置连续，后续跟随指针增量。导航目标即时持久保存，动画中间帧只影响显示；Back 后立即刷新恢复一级。减少动态效果设置直接到达最终状态。Done 截图采用当时实际呈现的坐标与像素，成员内容、caption、描边与阴影采用同一实际变换比例。

一级外框随成员几何更新，成员视觉区域外保留 24px 留白，顶部留 40px 标题空间。底部把现有 item 的 10px 标题间隔与 22px caption 一起纳入视觉区域，然后再留 24px；item 本体坐标与尺寸保持。二级修改作用于原 item，返回、切换模式和刷新保持结果。文件夹预览采用创建顺序的前 3 个存活成员，展示实际缩略图；文本/文件提供类型与内容提示。空组显示名称与 0 items，允许导入或解组。

## 视觉

沿用现有界面字体、图标、灰阶工具条和屏幕尺寸控制。文件夹采用平面、实色、无阴影、无边框的上开口造型：降低的后页、对齐的错层预览、带标签页的前封套。封套宽 216、高 224，前片从约 y64 延伸至底部，四角为 4px。底色为 Cobalt #315AD9、Sage #779D85、Coral #EA6848、Lilac #ADA0DE、Ink #202124、Sand #E7D9B7 之一；创建时随机选择并持久保存，刷新和模式切换保持。前后封套采用同色系的实色，前 3 个 item 的实际预览从上方露出，图片和视频铺满预览卡片。封面采用统一档案网格：左列细横线保持同长同线宽，顶部密集、向下间距逐步增大并延伸到距底部 12px；右列短横线、名称与真实 item 数量对齐，线条颜色实色且保持可读。下方 caption 保留原位名称编辑。参考图提供网格、对齐与线条上密下疏的节奏；品牌文字和社交界面属于参考内容。DOM 与截图合成共用线条坐标及文本排版。

## 数据与接口

group 属于项目白板。BoardObject 增加可选 groupId，原 assetId、ID、版本、来源与历史引用保留。独立 groups 表保存 group 记录，objects.group_id 保存唯一归属；BoardGroup 返回 id、name、mode（frame/folder）、color、x/y/width/height、version、createdAt、updatedAt 和按创建顺序排列的 objectIds。颜色类型为 cobalt、sage、coral、lilac、ink、sand。已有库通过一次 schema 迁移把 texture 列改为 color，并按已有主色映射：orbit→cobalt、grid→sage、rays→coral、steps→lilac、weave→ink、confetti→sand。旧截图与历史来源按保存时内容保留。frame 模式的几何保存展开框范围；folder 模式的 x/y 保存稳定的一级锚点，width/height 保存当前成员对应的展开尺寸，展示范围由固定尺寸换算。frame 成员变化刷新完整范围，folder 内部编辑保持一级锚点并刷新展开尺寸；成员变化均更新 group version。Expand on board 时整体平移当前成员，使其外框左上角对齐文件夹锚点，然后展开。

扩展现有 BoardOperation，UI 和 CLI 共用 POST /api/board/operations：

- group.create：group={id?,name?,objectIds,color?}，expectedVersions={objectId:version}，成员数至少 2，成员当前处于一级。
- group.update：groupId、expectedVersion、changes={name?,mode?,x?,y?}。坐标移动整体平移成员；状态切换在服务事务内计算周围布局。
- group.ungroup：groupId、expectedVersion，保留成员并清除归属。
- create 的 object 允许 groupId；二级创建时使用此字段。
- update 的 changes 允许 groupId:string|null，既有 item 可移入目标组或回到一级，同时保留对象、素材及来源身份。省略坐标保持当前 world 位置，显式坐标可调整组内布局；旧组和新组的范围与版本在同一事务内刷新，对象版本继续使用现有冲突检查。

CLI 的 `group list` 返回项目组；`group read --group ID` 返回 group、当前 displayBounds、coordinateSpace=world 和有序 members，每项包含原 object 与 asset 文件元数据。一级和二级共用项目 world 坐标，成员 x/y/width/height 表达真实布局；folder 的锚点与展开范围分别保留，当前一级占位由 displayBounds 表达。`group put --group ID --object ID --version V [--x X --y Y]` 委托同一对象 update，把既有 item 放入组。批量归组及返回一级通过 board operations，task complete 使用同一业务操作与来源/回执规则。

请求引用增加 `kind: group`，草稿的可选 groupIds 和 order 表达组来源与正文位置；既有草稿缺省为空。Resolved group 保存 BoardGroup、objects 与 assets，TaskSnapshot 的 requestReferences.groupIds 和 referenceContent.groups 明确组身份和冻结内容。组内成员仍保存在真实对象/素材来源集合中，正文以单个组引用展示。普通 object/task 引用、重复位置、UTF-16 偏移和任务范围规则沿用现有业务接口。

历史组与新增显式 item 可保留不同时间的来源。每个 occurrence 使用自己的解析来源；顶层去重对象/素材集合以显式 item 为优先。新增 item 读取当前对象与素材元数据，历史组及既有冻结 occurrence 保留其保存时的数据，引用来源集合与明确选择一致。

BoardState 和 board operations 响应增加 groups，BaseSceneSnapshot 携带组视觉数据供截图合成。原对象 API 保持现有语义；历史快照继续引用真实成员。SessionView 扩展 activeGroupId? 和 parentView?（x/y/zoom）；进入二级时保存一级 camera，返回时还原。服务器校验 group 归属，组被解散或删除时客户端回到一级。画板选择、命中、吸附、Fit、批注和截图使用当前可操作层；隐藏成员保持读取可用，避免被误报为已删除。AnnotationInput 增加 boardGroupId? 保存二级区域批注归属，缺省表示一级；对象批注跟随成员所在层。引用定位可以打开成员所属的文件夹。

## 布局切换

收起操作在一个短事务内读取当前成员、组和周围布局，先计算文件夹占位，再收拢右侧，然后收拢下方。周围布局以一级可见单元处理：普通 item、其他组外框、其他文件夹。一个组作为整体移动。

右侧候选的左边位于原框右边或更右，且垂直范围与原框相交；按从左到右处理。各候选尽量左移，最多移动原框宽减文件夹宽的正差，保持 24px 间距并由已经放置的可见单元阻挡。下方候选的上边位于原框下边或更下，且横向范围与原框相交；在右侧更新后按从上到下处理，尽量上移，最多移动高度差，保持相同间距。左上方及远离对应带状区域的 item 保持位置。碰撞候选允许保持原位，已有重叠不额外扩散。

展开保留成员内部相对布局，并锚定当前文件夹位置；扩大的框按右侧、下方顺序把相交邻居推到 24px 外，必要时传递到同方向邻居。相邻组整体移动。原外框小于文件夹的维度在收起时采用相同推开规则；正差维度仍按收拢规则执行。folder 直接 Ungroup 先完成展开时的成员归一和邻居避让，再清除组归属。切换使用当时位置计算，保留用户在收起期间做的编辑。采用主键、唯一归属、事务和普通 version 处理并发；冲突返回 409 并读取当前布局。

## 验收 A15

1. 真实框选两项出现 Group；分组外框、成员独立编辑、整体拖动、原位重命名、解组全部可用。group 非 item 空白处单击选中整组并可拖动；item 点击继续选中该 item。
2. 文件夹锚点精确等于外框左上角；右侧先左移，下方再上移，固定间距与障碍生效；覆盖负坐标、异形布局和相邻组。
3. 单击进入、Back 返回；一级视口恢复，二级导入/便签归组，移动/缩放/文本/媒体/批注/引用沿用当前流程。

5. 收起/展开/解组、刷新和服务重启保留成员、编辑、原素材和历史引用；跨任务范围看到同一 group。
6. 旧版本成员/组操作返回冲突，整次事务回滚；原有数据库升级、备份恢复、成员删除和空组均可用。
7. 浅色/深色、320/390px、键盘、减少动态效果；文件夹为 216×224 的实色封套、无边框、无阴影，前 3 个预览和随机颜色稳定，网格细线对齐。悬停直接显示选项且能移入操作条；Rename 输入与原名称位置一致，整组与成员保持普通外观。解组图标清晰表达分离。

9. 文件夹 caption 的鼠标/键盘/触屏选择可将同一成员正式引用到对话框，拖动和原位编辑保持；成员操作条避让 frame 标题，真实标题中心点击可选 group。
10. CLI 读取组、原文件信息与 world 布局；新建到二级及既有 item 移入/跨组/回到一级保持身份。旧对象版本、缺失目标和批次后续失败保持事务回滚，空组锚点及任务来源/回执规则通过。
