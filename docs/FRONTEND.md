# acanvas 前端设计

更新日期：2026-10-01。

## 视觉依据

采用灰、黑、白主配色，沿用相邻 `giga_components` 的字体、留白、控件尺度、圆角及轻量动效。素材保持其原始色彩。用户提供的两张输入区参考图确定底部输入框与上方任务条的关系。

## 项目画布

画布铺满窗口，左上角保留 acanvas 标识和实际项目名，以紧凑浮层呈现。导入、主题切换、左侧工具条和底部输入区独立悬浮。界面使用英文产品文案，默认视图保持简洁；必要操作具有英文 tooltip 与无障碍名称，错误和待处理反馈明确。素材与布局由项目共享。选择、平移、缩放比例、放大/缩小和适配视图合并为左侧垂直居中的紧凑工具条，宽约 40px，按钮约 32px，图标 16px。界面移除四角框的区域批注模式按钮；选中素材后的添加批注、旧区域数据与渲染继续保留。任务由宿主对话绑定，白板不提供独立会话管理。

## 上下文操作

选中素材后显示 Attach、Annotate、Delete 三个并列一级操作。点击 Annotate 后进入画布内二级标注：可直接输入整素材批注，也可在选中图片或视频上拖动区域再输入。Back 或 Escape 返回一级；切换选择时保留原目标的未提交输入与区域。所有操作保持就地完成。Enter 保存批注，Shift+Enter 换行，输入法候选确认保持正常输入。控件保持屏幕尺寸，随平移、缩放和布局变化跟随，空间不足时在邻近可操作区域调整。

未提交批注随目标在当前编辑上下文保留，发送主需求前保存非空批注；失效目标的未提交文字提供局部处理入口。

草稿中的批注和当前编辑区域使用淡蓝色标记。发送成功后，画布隐藏已发送批注；显式查看某个任务详情时，仅投影该任务快照中的批注，与当前草稿标记互斥。关闭或切换详情、取消任务及离开任务查看后隐藏投影，并恢复草稿标记。进入 Annotate 结束任务查看和读取。已发送快照与项目批注记录保持完整，目标已移除时在任务详情中保留文字和帧图。

视频播放条优先位于所选视频下方，空间不足时在素材邻近或画面内调整位置，与固定控件及输入区保留可操作间距。

## 吸附与对齐

拖动素材时，其外框边缘与中心线可吸附到视野内其它素材的边缘或中心线；多选时以整体外框移动，保持内部相对位置。吸附范围按屏幕距离计算，缩放后手感一致，并显示轻量对齐参考线。对象吸附默认启用，按住 Alt 临时自由移动；纯点击保持素材位置。选择两个或更多素材后，可直接执行左对齐、水平居中、右对齐、顶对齐、垂直居中和底对齐，以选区整体边界为基准，保持素材尺寸与未选中内容。

## 就地展开

任务详情在队列行内展开，历史记录在同一输入区上方切换查看。草稿冲突直接呈现两份内容与保留选择；复制接续口令失败时直接显示可选文本。任务素材优先定位到画布中的对应对象，已移除对象的媒体在任务内容中预览，普通文件直接下载。这些交互保持画布可操作，并使用局部展开与滚动容纳长内容。

## 视频交互

视频画面与图片采用一致的选择与拖动操作。单击选中，拖动移动；播放通过选中视频后显示的独立播放控件触发。播放、暂停和时间轴使用同一视频元素，批注保存当前时点及可用的帧预览。播放控件支持键盘操作，并与画布手势分离。播放条与左侧工具条始终保留可操作间距。

## 输入区与队列

输入框初始保持紧凑单行，随自动换行或手动换行向上扩展，到达视口允许的最大高度后内部滚动。Enter 发送，Shift+Enter 换行；输入法候选确认保持正常输入。草稿恢复时同步高度，发送后收回初始高度。输入框移除“+”及文件选择入口，素材和批注引用以紧凑标签显示在输入框内部上方，长名称截断，超出宽度时横向滚动；添加成功直接以标签呈现，省去额外成功提示。textarea 无背景 highlight、outline、边框和阴影；默认视图去掉保存状态及快捷键说明；记录与接续操作以紧凑图标保留。按钮和内联输入保留清晰的键盘焦点。

队列贴着输入框上沿并略微内缩，行高保持紧凑。1–3 条任务标题直接可读，更多任务通过明确的展开按钮查看；鼠标悬停及单纯焦点进入保持布局和背景稳定。任务详情继续在行内展开，较长列表局部滚动。

展开与收起由明确操作控制，键盘与触屏可使用同一入口。发送成功后，新任务以短促的淡入和轻微位移动效进入可见队列；失败、历史加载和状态刷新保持现有列表稳定。系统减少动态效果设置显示即时结果。

队列根据工具条右边界和 dock 左边界连续保留间距，覆盖窄屏与中等宽度；展开时工具按钮保持实际可点击。

## 动效

沿用灰阶视觉及现有字体，以短促、柔和的浮层显现、按钮反馈和输入框伸展强化操作连贯性。拖动、缩放及控件跟随保持即时响应。系统减少动态效果设置关闭非必要动画。

## 粘贴与导入

文件无论从画布、输入框还是其他入口粘贴、拖拽或选择，都先导入共享画布。画布内拖放按实际坐标放置，输入区文件在可见画布中心放置。普通文本继续编辑；用户通过选中素材或添加批注建立需求引用，原有引用保留。导入失败或离线提供明确反馈。

Finder 原生文件粘贴的当前证据为用户在真实内置浏览器手工确认；合成事件与 PNG 自动化分别记录其验证范围。生产导入通过浏览器 File 数据，不从粘贴文本推断任意本地路径。

## 验证

检查全屏画布、紧凑项目身份、英文标签与独立悬浮控件、亮/暗主题、自适应输入高度、Enter 发送、Shift+Enter 换行及 IME 候选确认，覆盖草稿恢复、发送后收回、引用保留及无 highlight。检查素材上下锚定、多选联合边界、平移缩放与移动缩放跟随，以及 320/390×480 短屏中的边缘调整、queue 滚动和控件中心实际命中。队列检查明确展开、悬停与焦点稳定、逐次成功发送动效和减少动态效果设置。吸附与对齐检查缩放后的距离阈值、多选相对位置、Alt 绕过、六向命令、刷新恢复和窄屏控件。保留视频播放、定位与帧批注回归。自动化使用隔离项目，用户正式数据与系统剪贴板保持原样。
