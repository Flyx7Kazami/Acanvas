# acanvas 前端设计

更新日期：2026-10-13。

## 视觉依据

采用灰、黑、白主配色，沿用相邻 `giga_components` 的字体、留白、控件尺度、圆角及轻量动效。素材保持其原始色彩。用户提供的两张输入区参考图确定底部输入框与上方任务条的关系。

## 项目画布

画布铺满窗口，左上角保留 acanvas 标识和实际项目名，以紧凑浮层呈现。导入、主题菜单、顶部工具条和底部输入区独立悬浮。主题按钮点开后选择 Light、Dark 或 Follow system，后者跟随系统外观。界面使用英文产品文案，默认视图保持简洁；必要操作具有英文 tooltip 与无障碍名称，错误和待处理反馈明确。素材与布局由项目共享。选择、平移、标记、便签、回退/前进、缩放比例、放大/缩小和适配视图合并为顶部居中的横向工具条，按钮约 32px，图标 16px，分隔线竖向排列。窄窗口的工具条位于项目名下方，超出可用宽度时横向滚动；底部输入区采用对称间距。便签在点击处放下一张纯文本卡片。选中一张便签后，删除按钮右侧是调色板图标，悬停后上方用圆点选择低饱和背景，第一项是黑白各半的默认色。Markdown 块右上角用眼睛和源码图标在预览与编辑之间切换，默认是预览。界面移除四角框的区域批注模式按钮；选中素材后的添加批注、旧区域数据与渲染继续保留。任务由宿主对话绑定，白板不提供独立会话管理。

初始化且没有素材时，画布中心保持纯空白，不显示 SVG 插图、Drop files to start 标题或导入说明。拖入文件时仍提供落点提示，导入入口、粘贴和画布操作保持可用。

## 更新信息

提示固定在距视口右侧、底部各16px的角落。短提示按内容宽度显示，上限约320px；右侧可用空间不足时收窄，文字保持单行并以省略号截断，完整文案保留在DOM和无障碍播报中。普通提示最窄44px，窄态缩小内边距和状态图标，指针事件穿透，保留底层输入与发送操作。含恢复操作的提示保持至少200px可用宽度（受视口边距限制），文字同样省略，按钮保持完整可点。控件变化只调整提示宽度，位置始终固定；操作恢复控件期间保持宽度稳定。

右下角普通操作反馈短暂显示，每条于 2.8 秒后独立消失，新反馈不延长旧反馈的寿命。仅在快速连续操作导致多条未过期提示同时存在时，显示最新一条与后方最多两层逐层内缩的薄背板；最多暂存五条，过期后自然恢复单条或清空。不显示数量角标、折叠标志或额外焦点入口，不主动展开、不抢焦点、不要求手动关闭。

成功提示和普通操作错误的展示副本使用这一短暂反馈；展示到期不修改实际失败状态。进行中的上传/重连、项目变化或保存失败等需要用户恢复的状态独立直显，不加入折叠栈，保留取消、重试及重开动作。窄屏按固定角落和文字省略规则呈现，亮暗主题和减少动态效果均覆盖。

## 上下文操作

选中素材后显示 Attach、Annotate、Delete 三个并列一级操作。点击 Annotate 后进入画布内二级标注：可直接输入整素材批注，也可在选中图片或视频上拖动区域再输入。Back 或 Escape 返回一级；切换选择时保留原目标的未提交输入与区域。所有操作保持就地完成。Annotate 操作、画布编号标记及输入框批注引用使用同一气泡图形；编号位于气泡内。一级 Annotate 操作采用灰阶描边，已创建批注的画布标记及引用保留淡蓝色。一级工具按可见轮廓和视觉重量分别定尺寸，按钮命中区域保持一致。Enter 保存批注，Shift+Enter 换行，输入法候选确认保持正常输入。控件保持屏幕尺寸，随平移、缩放和布局变化跟随，空间不足时在邻近可操作区域调整。

未提交批注随目标在当前编辑上下文保留，发送主需求前保存非空批注；失效目标的未提交文字提供局部处理入口。

草稿中的批注和当前编辑区域使用淡蓝色标记。发送成功后，画布隐藏已发送批注；显式查看某个任务详情时，仅投影该任务快照中的批注，与当前草稿标记互斥。关闭或切换详情、取消任务及离开任务查看后隐藏投影，并恢复草稿标记。进入 Annotate 结束任务查看和读取。已发送快照与项目批注记录保持完整，目标已移除时在任务详情中保留文字和帧图。

视频播放条优先位于所选视频下方，空间不足时在素材邻近或画面内调整位置，与固定控件及输入区保留可操作间距。

## 吸附与对齐

拖动素材时，其外框边缘与中心线可吸附到视野内其它素材的边缘或中心线；多选时以整体外框移动，保持内部相对位置。吸附范围按屏幕距离计算，缩放后手感一致，并显示轻量对齐参考线。对象吸附默认启用，按住 Alt 临时自由移动；纯点击保持素材位置。Shift 多选后悬停 Align，上方出现六向对齐；左对齐、水平居中、右对齐、顶对齐、垂直居中和底对齐仍以选区整体边界为基准，保持素材尺寸与未选中内容。

## 就地展开

任务详情在队列行内展开，历史记录在同一输入区上方切换查看。历史面板四角统一20px圆角，空状态和滚动内容均保持下方圆角裁切；其他队列面板沿用自身连接样式。草稿冲突直接呈现两份内容与保留选择；复制接续口令失败时直接显示可选文本。任务素材优先定位到画布中的对应对象，已移除对象的媒体在任务内容中预览，普通文件直接下载。这些交互保持画布可操作，并使用局部展开与滚动容纳长内容。

## 视频交互

视频画面与图片采用一致的选择与拖动操作。单击选中，拖动移动；播放通过选中视频后显示的独立播放控件触发。播放、暂停和时间轴使用同一视频元素，批注保存当前时点及可用的帧预览。播放控件支持键盘操作，并与画布手势分离。播放条与左侧工具条始终保留可操作间距。可解码视频的引用缩略图显示首帧，生成缩略图保持画布视频播放状态和时点；预览不可用时显示文件类型标识。

## 文档交互与滚轮归属

HTML默认展示快照，鼠标进入内容区、键盘聚焦或触屏操作自动激活，无Interact按钮；移出鼠标后可继续运行。同页最多4个实例，重复进入更新最近使用顺序，新请求释放最久未使用的实例并保留快照。Stop在当前悬停期间有效，重新进入或明确键盘/触屏操作可恢复。

画布滚轮与控件点击/拖拽职责分离：普通滚轮默认平移画布，Ctrl/Meta滚轮及触控板缩放按指针位置缩放。音频时间轴、HTML、视频和工具控件共用入口；Markdown及长批注正文显式保留普通阅读滚动，修饰键缩放仍交画布。新增组件通常只需声明自己的阅读区域，其余继承默认行为。画布外输入区保持自身交互。见[画布输入职责](CANVAS_INPUT.md)和[HTML悬停交互](HTML_HOVER_INTERACTION.md)。

## 音频交互

采用用户选择的 A · Cover above，保留22px整体圆角、12px封面圆角、圆形播放键和完整波形。封面按自然比例完整显示并填满可用槽位约束，横向占位跟随实际图片宽度。紧凑/宽幅保持横向，方形/竖形按实际尺寸切换为上方封面、下方紧凑控制；整块使用同一主题表面并铺满容器。字号以原版紧凑尺寸为基准，随节点尺寸连续变化，画布缩放自然作用一次。浅色使用#e7e7e7表面、#202020主文字、#505050辅助文字和#686868未播放波形，深色沿用深灰与近白前景。主题切换立即重绘暂停中的波形，播放位置保持。指针点击/拖动时间轴保持正常轮廓和背景，Tab键盘进入时提供清晰焦点。拖拽定位、键盘定位、真实播放和批注继续操作原音频元素。参见[圆角音频方案](AUDIO_PLAYER_REDESIGN.md)。

## 输入区与队列

输入框在空白、失焦且无待处理请求时收为280px，窄屏取280px与可用dock宽度减64px中的较小值，320px视口下约224px；高度保留52px。紧凑提示为简短的“Create…”，聚焦输入区域后展开到原有可用宽度并显示完整提示。已有文本、引用、编辑任务和待处理请求保持可用的展开状态。

用户在聊天内比较后选择“更多菜单”。输入框左内嵌一个省略号入口，向上打开Request history与Copy resume prompt两项操作，原底部按钮行移除。菜单位于共享容器内、表单外侧，保留输入框圆角裁切并让弹层完整显示。历史使用现有面板，Copy使用真实复制及失败后的接续文本回退。

宽度动画只作用于共享容器。进入输入区域才触发展开，More和菜单获得焦点时保留当前宽度，保证按下至释放期间点击目标稳定。再次点击入口或Escape关闭，菜单支持方向键、Home/End和确认操作；Escape、Copy完成及历史关闭返回More入口。外部点击关闭时焦点跟随用户点击的目标。队列、历史、草稿冲突和接续文本等阅读区域保留原有宽度。紧凑状态外围透明区域允许操作后方画布；减少动态效果设置直接切换宽度。

输入框初始保持紧凑单行，随自动换行、手动换行或正文引用向上扩展，到达视口允许的最大高度后内部滚动。Enter 发送，Shift+Enter 换行；输入法候选确认保持正常输入。草稿恢复时同步高度，发送后收回初始高度。每个普通素材引用在正文光标处独立显示，包含缩略图、名称和移除入口；文字编辑同步移动引用，刷新与队列编辑恢复位置。输入框移除“+”及文件选择入口，显式附件与批注使用紧凑标签，24px 缩略图配合协调的内外圆角；标签在输入框内部上方横向滚动，文字截断且保留完整名称访问；添加成功直接以标签呈现，省去额外成功提示。正文编辑区保持无背景 highlight、outline、边框和阴影；默认视图去掉保存状态及快捷键说明；记录与接续操作以紧凑图标保留。按钮和内联输入保留清晰的键盘焦点。空态尺寸保持，内容态高度按真实排版自适应。

全局点批注的编号中心位于实际点击点，平移、缩放及评论开合时继续跟随该点。评论框在邻侧独立避让工具栏、输入栏和其他编号；同点或邻近多条评论可错开文字框，各自编号保持锚定。点位及正文交互的完整规则见[调整设计](chatbox/INLINE_REFERENCES_POINT_ANCHOR_DESIGN.md)。

队列贴着输入框上沿并略微内缩，行高保持紧凑。待办以最左侧空心圆表示，运行中以同位置旋转圆圈表示；预览存在时状态图标仍可见。队列相对输入框左右对称内缩，并保持工具条可操作间距。1–3 条任务标题直接可读，更多任务通过明确的展开按钮查看；鼠标悬停及单纯焦点进入保持布局和背景稳定。任务详情继续在行内展开，较长列表局部滚动。单行展示最多三个快照预览，超出的项以 +N 表示。每条批注保留独立预览，使用帧图或源素材并带气泡标识；对应源图和帧图作为批注预览的一部分，素材列表去掉这些重复项。

展开与收起由明确操作控制，键盘与触屏可使用同一入口。发送成功后，新任务以短促的淡入和轻微位移动效进入可见队列；失败、历史加载和状态刷新保持现有列表稳定。系统减少动态效果设置显示即时结果。

队列根据工具条右边界和 dock 左边界连续保留间距，覆盖窄屏与中等宽度；展开时工具按钮保持实际可点击。

## 动效

沿用灰阶视觉及现有字体，以短促、柔和的浮层显现、按钮反馈和输入框伸展强化操作连贯性。拖动、缩放及控件跟随保持即时响应。系统减少动态效果设置关闭非必要动画。

## 粘贴与导入

文件无论从画布、输入框还是其他入口粘贴、拖拽或选择，都先导入共享画布。画布内拖放按实际坐标放置，输入区文件在可见画布中心放置。普通文本继续编辑；用户通过选中素材或添加批注建立需求引用，原有引用保留。导入失败或离线提供明确反馈。

Finder 原生文件粘贴的当前证据为用户在真实内置浏览器手工确认；合成事件与 PNG 自动化分别记录其验证范围。生产导入通过浏览器 File 数据，不从粘贴文本推断任意本地路径。

## 验证

检查全屏画布、紧凑项目身份、英文标签与独立悬浮控件、亮/暗主题、自适应输入高度、Enter 发送、Shift+Enter 换行及 IME 候选确认，覆盖草稿恢复、发送后收回、引用保留及无 highlight。检查素材上下锚定、多选联合边界、平移缩放与移动缩放跟随，以及 320/390×480 短屏中的边缘调整、queue 滚动和控件中心实际命中。队列检查明确展开、悬停与焦点稳定、逐次成功发送动效和减少动态效果设置。吸附与对齐检查缩放后的距离阈值、多选相对位置、Alt 绕过、六向命令、刷新恢复和窄屏控件。保留视频播放、定位与帧批注回归。自动化使用隔离项目，用户正式数据与系统剪贴板保持原样。
