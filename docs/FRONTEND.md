# acanvas 前端设计

更新日期：2026-10-01。

## 视觉依据

采用灰、黑、白主配色，沿用相邻 `giga_components` 的字体、留白、控件尺度、圆角及轻量动效。素材保持其原始色彩。用户提供的两张输入区参考图确定底部输入框与上方任务条的关系。

## 项目画布

画布铺满窗口。导入、主题切换、左侧工具条和底部输入区独立悬浮在画布上。界面使用英文产品文案；品牌与项目 header、画布标题与素材计数、保存状态和发送快捷键提示从默认视图移除。必要的图标操作通过英文 tooltip 与无障碍名称识别，错误与待处理反馈保持明确。素材与布局由项目共享。选择、平移、缩放比例、放大/缩小和适配视图合并为左侧垂直居中的紧凑工具条，宽约 40px，按钮约 32px，图标 16px。界面移除四角框的区域批注模式按钮；选中素材后的添加批注、旧区域数据与渲染继续保留。任务由宿主对话绑定，白板不提供独立会话管理。

## 视频交互

视频画面与图片采用一致的选择与拖动操作。单击选中，拖动移动；播放通过选中视频后显示的独立播放控件触发。播放、暂停和时间轴使用同一视频元素，批注保存当前时点及可用的帧预览。播放控件支持键盘操作，并与画布手势分离。播放条与左侧工具条始终保留可操作间距。

## 输入区与队列

底部输入框固定单行视觉高度 52px，文字与发送在同一行；textarea 内容区 24px、padding 为 0，通过内部滚动保留长文本和既有多行草稿。输入框移除“+”及文件选择入口，已有素材引用与批注位于框外上方的单行横滚细条。textarea 无背景 highlight、outline、边框和阴影；默认视图去掉保存状态及快捷键说明；记录与接续操作以紧凑图标保留。按钮与对话框保留键盘焦点。

队列贴着输入框上沿并略微内缩。1–3 条任务的标题均可读；超过 3 条显示叠层及数量，悬停向上展开更多任务，输入框位置保持稳定。展开列表有高度上限和滚动，鼠标经过两者之间保持连续。键盘和触屏有等效展开入口。

展开与收起采用同一可见状态：一次点击即可收起，当前悬停或焦点保持时维持用户的收起决定，离开后再次进入可重新展开。任务详情关闭后恢复正确焦点；记录入口保留回执和已完成内容。

队列与引用条根据工具条右边界和 dock 左边界连续保留间距，覆盖窄屏与中等宽度；展开时工具按钮保持实际可点击。

## 粘贴与导入

文件无论从画布、输入框还是其他入口粘贴、拖拽或选择，都先导入共享画布。画布内拖放按实际坐标放置，输入区文件在可见画布中心放置。普通文本继续编辑；用户通过选中素材或添加批注建立需求引用，原有引用保留。导入失败或离线提供明确反馈。

Finder 原生文件粘贴的当前证据为用户在真实内置浏览器手工确认；合成事件与 PNG 自动化分别记录其验证范围。生产导入通过浏览器 File 数据，不从粘贴文本推断任意本地路径。

## 验证

检查全屏画布、无 header、英文标签与独立悬浮控件、亮/暗主题、52px 单行输入、旧多行草稿与引用保留、无文件添加按钮、所有文件进入画布、左侧合并工具、1/3/6 项队列及焦点。检查 390/560/768/1024/1440 宽度下 1/3/6 项 queue 展开、工具按钮中心实际命中，以及长草稿刷新与发送内容完整。自动化使用隔离项目，用户正式数据与系统剪贴板保持原样。
