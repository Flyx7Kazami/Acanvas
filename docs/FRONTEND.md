# acanvas P0 前端设计

## 风格依据

用户指定参考相邻项目 `giga_components`，并明确采用灰、黑、白主配色。沿用 Giga 的 Google Sans/PingFang 字体体系、控件尺度、圆角、留白和轻量动效。主题、选中态和批注以明暗、描边及编号表达。

本地参考包括 `packages/tokens/src/styles.css`、字体资源，以及 NotesComposer、MediaCard、ImagePreview、LanguageSelect 的交互模式。实际复用资源保留其许可证；acanvas 的运行包包含自己的资源和实现。

## 布局

顶部显示项目、连接/保存状态、导入与主题操作。左侧是当前项目的会话入口。中部为共享画布，素材占主要视觉空间。右侧显示当前会话的需求、队列和底部输入区。底部悬浮工具条提供选择、平移、标注、缩放与适配视图。窄屏折叠辅助面板。

## 交互

画布接收素材，输入区接收当前需求附件。对象选择与区域批注保留清晰编号；视频批注关联时间与画面。对象位置属于共享布局，视口和草稿属于会话。发送期间明确反馈保存状态，任务状态以服务端记录为准。

选区坐标以实际媒体内容区域为基准，平移和缩放统一转换。异步草稿保存绑定 session ID 与 draft ID，切换会话和发送后的迟到响应按原归属处理。

## 验证

检查亮色、暗色、窄屏、键盘焦点、粘贴目标、浮层主题和 reduced motion。浏览器验证使用独立临时项目，记录实际覆盖范围。真实系统剪贴板兼容性按实测声明。
