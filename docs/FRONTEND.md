# acanvas 前端设计

更新日期：2026-10-01。

## 视觉依据

采用灰、黑、白主配色，沿用相邻 `giga_components` 的字体、留白、控件尺度、圆角及轻量动效。素材保持其原始色彩。用户提供的两张输入区参考图确定底部输入框与上方任务条的关系。

## 项目画布

画布铺满窗口，左上角保留 acanvas 标识和实际项目名，以紧凑浮层呈现。导入、主题切换、左侧工具条和底部输入区独立悬浮。界面使用英文产品文案，默认视图保持简洁；必要操作具有英文 tooltip 与无障碍名称，错误和待处理反馈明确。素材与布局由项目共享。选择、平移、缩放比例、放大/缩小和适配视图合并为左侧垂直居中的紧凑工具条，宽约 40px，按钮约 32px，图标 16px。界面移除四角框的区域批注模式按钮；选中素材后的添加批注、旧区域数据与渲染继续保留。任务由宿主对话绑定，白板不提供独立会话管理。

## 上下文操作

选中操作条贴近素材上方，多选时以选区整体为锚点。视频播放条优先位于所选视频下方，空间不足时在素材邻近或画面内调整位置。控件保持稳定的屏幕尺寸，随画布平移、缩放和素材布局变化跟随；靠近边缘时调整位置，与固定控件及输入区保留可操作间距。

## 视频交互

视频画面与图片采用一致的选择与拖动操作。单击选中，拖动移动；播放通过选中视频后显示的独立播放控件触发。播放、暂停和时间轴使用同一视频元素，批注保存当前时点及可用的帧预览。播放控件支持键盘操作，并与画布手势分离。播放条与左侧工具条始终保留可操作间距。

## 输入区与队列

输入框初始保持紧凑单行，随自动换行或手动换行向上扩展，到达视口允许的最大高度后内部滚动。Enter 发送，Shift+Enter 换行；输入法候选确认保持正常输入。草稿恢复时同步高度，发送后收回初始高度。输入框移除“+”及文件选择入口，已有素材引用与批注位于框外上方的单行横滚细条。textarea 无背景 highlight、outline、边框和阴影；默认视图去掉保存状态及快捷键说明；记录与接续操作以紧凑图标保留。按钮与对话框保留键盘焦点。

队列贴着输入框上沿并略微内缩。1–3 条任务的标题均可读；超过 3 条显示叠层及数量，悬停向上展开更多任务，输入框位置保持稳定。展开列表有高度上限和滚动，鼠标经过两者之间保持连续。键盘和触屏有等效展开入口。

展开与收起采用同一可见状态：一次点击即可收起，当前悬停或焦点保持时维持用户的收起决定，离开后再次进入可重新展开。任务详情关闭后恢复正确焦点；记录入口保留回执和已完成内容。

队列与引用条根据工具条右边界和 dock 左边界连续保留间距，覆盖窄屏与中等宽度；展开时工具按钮保持实际可点击。

## 动效

沿用灰阶视觉及现有字体，以短促、柔和的浮层显现、按钮反馈和输入框伸展强化操作连贯性。拖动、缩放及控件跟随保持即时响应。系统减少动态效果设置关闭非必要动画。

## 粘贴与导入

文件无论从画布、输入框还是其他入口粘贴、拖拽或选择，都先导入共享画布。画布内拖放按实际坐标放置，输入区文件在可见画布中心放置。普通文本继续编辑；用户通过选中素材或添加批注建立需求引用，原有引用保留。导入失败或离线提供明确反馈。

Finder 原生文件粘贴的当前证据为用户在真实内置浏览器手工确认；合成事件与 PNG 自动化分别记录其验证范围。生产导入通过浏览器 File 数据，不从粘贴文本推断任意本地路径。

## 验证

检查全屏画布、紧凑项目身份、英文标签与独立悬浮控件、亮/暗主题、自适应输入高度、Enter 发送、Shift+Enter 换行及 IME 候选确认，覆盖草稿恢复、发送后收回、引用保留及无 highlight。检查素材上下锚定、多选联合边界、平移缩放与移动缩放跟随，以及 320/390×480 短屏中的边缘调整、queue 滚动和控件中心实际命中。保留视频播放、定位与帧批注回归，检查系统减少动态效果设置。自动化使用隔离项目，用户正式数据与系统剪贴板保持原样。
