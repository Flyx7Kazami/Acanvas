# 灰阶动画对比

- `previous.html`：先前右上→左下的灰阶预览。
- `current.html`：当前右下→左上的独立副本，与保存时的主预览逐字节一致。
- `comparison.html`：两版使用相同背景、64px 加载尺寸和同步时刻并排播放；也可直接离线打开。
- `preview.png`：同一时刻的紧凑并排截图。

## 先前版的还原依据

完整历史 HTML 没有保留，因此先前版是按留存源码参数和渲染结构重建。其 70,942 字节大小与首次灰阶构建记录相同。以原先的 160×128 视口、DPR2 和 0、75、150、225、300、375、450、525ms 重拍后，1280×512 拼图与留存的 [reference-strip.png](reference-strip.png) 在实现侧核对中逐像素一致：差异像素 0，最大通道差 0。独立复核的同组重拍在 450ms 时有 1 个边缘像素差异，最大通道差 20，其余时刻一致；两次观察均保留。详情见 `provenance.json` 和[独立像素复核](../../../../docs/evidence/domino-camera-loading/comparison-review-20261013/historical-pixel-review.json)。

## 实际差别

两版保留相同的灰阶、14 单位间距、15 个内部槽位、接触运动、300ms 推进节奏、比例和 72×64 取景范围。

视角方位从 −35° 变为 −145°（215°），使世界前进向量的屏幕 y 分量由正变负。先前版的卡面倒下时经过接近侧面的窄面姿态，再展开；当前视角中的卡面一直保持较宽的可见面，因此更像连续的带状排列。

先前版同时保留当时的卡面中心深度排序。当前版使用适合其视角的铰链深度顺序。对比页保留这项历史渲染差别，供判断实际质感。

这些页面仅用于独立比较。此次没有修改主模型、生成文件、主预览、静态产品图标或运行服务。
